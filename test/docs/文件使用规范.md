# 文件使用规范（`test/`）

> 适用于 `test/` 下所有脚本、TB、探针。目标：文件只落在推荐位置，不制造第二套路径。

**判定口径**：违规只看**代码事实**——`文件:行` + 触发条件 + 它算出的路径；推荐路径当时可用却没被使用，才算泄露。
磁盘上有没有残留文件**不构成证据**（可能来自旧版本、一次性脚本、重构前代码）；盘干净也不等于合规。

## 1. 只允许写这三处

| 位置 | 放什么 | 怎么取 |
|---|---|---|
| 客户端 work root | 桥运行时产物、临时文件、日志 | 入口 `init_work_dir()`；用 `work_root()/temp_dir()/log_dir()/artifact_dir()` |
| 远端 role root | 部署产物、远端临时文件 | 注册表 `roles.<role>.root`（默认 `~/.virtuoso-bridge/<user>/`） |
| 个人工程目录 | Cadence 工程产物、导出、证据 | `~/project/<user>/`；证据另可放 `test/artifacts/evidence/<run-id>/` |

`test/` 内的固定落点（详见 [`证据与报告.md`](证据与报告.md)）：环境 `test/artifacts/env/`、产物 `test/artifacts/evidence/`、零时产物 `test/artifacts/tmp/`（可随时删）；仓库根不得出现任何运行产物（如 `.coverage*`、`*.log`）。

## 2. 禁止清单

1. 共享 `/tmp`、`/var/tmp`（唯一例外：设计内的 `/tmp/virtuoso_bridge_<user>/<client_id>/` 部署目录，见问题登记 P-011）；
2. `$HOME` 根下新建任何东西（`panic.log*`、`tb_*.log`、脚本、备份都不行）；
3. 字面量 `~` 目录；把绝对路径拍平成 `homeGent.xxx` 这类目录；
4. 脚本放 `$HOME` 或 `~/Desktop`（脚本必须进仓库 `test/`、`tools/`）；
5. 跨用户共享 scratch；
6. 用户名含空格、`/`、`~`（只允许 `[a-z0-9_-]+`）；
7. 依赖进程 cwd 落盘（路径必须显式）；
8. 离线级（`unit`/`integration`/`scenario`）用例在仓库里落文件或残留临时目录（临时目录用 `tempfile.mkdtemp(prefix="vb-")`，由 `test/conftest.py` 清理）。

## 3. 自检

```bash
# 远端：60 分钟内 $HOME 根被改动的条目，应只出现 project/ 与 .virtuoso-bridge/
find ~ -maxdepth 1 -mmin -60 -printf '%TY-%Tm-%Td %TH:%TM  %p\n' | sort
```
