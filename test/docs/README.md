# 测试入门（`test/docs/`）· 给工程师

> 这一页只做导航：测试在哪、新用例放哪、要查什么去哪个文档。
> **规则本身不在这里重复**——两份参考手册是唯一出处。

## 0. 测试在哪、新用例放哪

```text
test/
├── offline/   不需要真机（unit / integration / scenario 进 CI）
├── semi/      要真机，但只跑单点 / 定位
├── live/      全真环境验收（packages / flows / registration / transport / stress / e2e）
├── shared/    夹具与 runner
├── docs/      规范（本页）
├── reports/   报告与缺陷跟踪（测试侧维护）
├── plans/     测试计划
└── artifacts/ 运行数据（env / evidence / tmp，默认不进 git）
```

- 不需要真机 → `offline/`；要真机但只验证单点 → `semi/`；全真验收 → `live/`。
- 离线怎么跑（两份手册里没有这条）：
  `python -m pytest test/offline/unit test/offline/integration test/offline/scenario`
- 真机怎么跑：实例、token、环境自检、常用命令全在
  [环境与场景.md](环境与场景.md) §2 / §5 / §6，照抄即可。
