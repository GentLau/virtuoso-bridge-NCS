## 2. 审计报告怎么写

命名 `<主题>-<YYYY-MM-DD>.md`；同主题复审计用新日期，旧报告保留（历史不覆盖）。
必备六项：范围与口径 / 方法（可复现命令） / 结论表（`编号｜归属｜文件:行｜代码事实｜应写路径｜触发条件｜建议｜级别`） / 反例（合规项）/ 未覆盖与不确定项 / 登记编号。

判定口径（用户 2026-09-22 裁定）：**只认代码事实**——`文件:行` + 触发条件 + 算出的路径；
磁盘上有没有残留文件**不构成证据**。推荐路径的定义见 [`../docs/文件使用规范.md`](../docs/文件使用规范.md)。

## 3. 规则

- 只审计，不改业务代码；修复另有负责人，审计者不给自己发结论；
- 每条结论要有 `文件:行` 与可复现命令，不接受"我搜过了"；
- 结论逐条登记进 [问题登记.md](问题登记.md)，报告只留证据；
- 中间文件按规范落盘，禁止写共享 `/tmp`。
