## A. 待修 / 待决策

### A-0　P-056 [P1・Linux 专属] `supervisor._force_kill_tree` 在 POSIX 下 NameError，强杀不生效

* **事实**：`src/server/supervisor.py:281` 的 `_force_kill_tree` 是 `@staticmethod`，POSIX 分支里却调 `self._signal_process_group(...)`（`:301`/`:306`）→ `NameError: name 'self' is not defined`。Windows 分支走 `taskkill` 不受影响。
* **影响**：spec《控制面与业务面》§3 的"`process/restart` 30s 排空后强杀业务进程组及 SSH 后代"在 Linux 上不成立；子进程组可能成孤儿继续占端口/SSH。
* **复现**：Linux 3.9/3.14 三条既有用例红（`test_process_lifetime.py::…process_group_descendant`、`test_supervisor_internals.py::TestForceKillTree::test_posix_group_*`），证据 `round5-linux-client/{py39,py314}.log`
* **修复建议**：把 `_force_kill_tree` 改回实例方法，或改调 `BusinessProcess._signal_process_group(...)`（一行级）。
* **验收**：上述 3 条在 Linux 转绿；`round5-Linux客户端矩阵.md` 的剩余红数从 6/8 降到 3/5（仅 P-055 等）。

### A-1　P-055 [P2] 业务面对"已定义路径 + 错误方法"返回 404 而非 405 + Allow

* **事实**：`src/server/api_server.py:127-161`（`do_GET` 兜底 404）、`:163-166`（`do_POST` 兜底 404）。实测 `GET /api/operation`、`POST /health`、`POST /help` 均 404 且无 `Allow`；同一规则控制面已实现（405 + Allow）。
* **复现**：`pytest test/offline/unit/test_api_server_method_not_allowed.py -q`（**3 红 2 绿**；绿=既有 `PUT /api/operation` 与未定义路径护栏）；真机 Surface 证据 `round5-live-api/business-port-surface.json`
* **验收**：3 条转绿、2 条护栏保持绿。

### A-2　P-057 [**非产品 bug**：解释器差异下的测试断言口径 · 已关闭] 深嵌套 JSON 拒绝行为随解释器变化

* **事实**：5000 层嵌套在 py3.9 → `RecursionError` → `400 invalid JSON body`；py3.14 连 20000 层都能解析（随后按普通请求 400/业务处理）。旧断言把 CPython 实现细节当契约。
* **用户 2026-09-24 判定**：**不是产品 bug，是解释器差异下的测试断言口径问题** ⇒ 本条**不作为产品缺陷**。
* **测试侧已处置（R5）**：long-int 仍钉死 `invalid JSON body`；deep 只钉安全不变量（400 或 200 + 可解析 JSON 壳 + 无断连）；另加「200000 层必须 400」的跨版本硬边界。
* **产品侧“显式深度上限”**保留为**建议**（可选加固），不立案、不阻塞。

### A-3　P-060 [**非源码 bug**：测试覆盖缺口 · 待测试侧（我）] calibre 包此前 0 真机入口

* **事实**：常驻注册表无任何 `role.command.calibre.bin`；`test/live/packages/` 无 calibre 套件；`run_all_http.py` SUITES 不含 calibre ⇒ 新注册的 calibre 包只能跑 offline 单测/direct 探针。
* **用户 2026-09-24 判定**：**测试覆盖缺口，不是源码 bug** ⇒ 处置归测试侧。
* **本轮已补**：专用 work-dir `test/artifacts/env/s11-calibre`（token `vb-s11cal`）+ 独立业务面 **8128** + `test/semi/probes/calibre_package_http_probe.py`；实测 `check_env` ok（v2025.1_16.10）、`drc` completed（1737 rulechecks / 36 results）、`lvs` completed（NOT COMPARED）。
* **建议固化**：① 常驻注册表加 calibre 事实（改后需重启 8127，或把专用环境写进 `test/docs/推荐测试环境.md` §S1）；② 新增 `test/live/packages/calibre_e2e_tests.py` 并加入 `run_all_http.py` SUITES；③ 修完 P-059/061/062 后用本探针回归。
