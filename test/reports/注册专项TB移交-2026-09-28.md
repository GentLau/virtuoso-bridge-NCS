## P5：host-key 轮换（等 rotate 脚本）

P5 需要测试侧先补一个**独占 w4-gent**的轮换脚本，TB 侧接口建议固定为：

```text
# 在 w4-gent 上执行，或通过 ssh w4-gent 调
w4_hostkey_cycle.sh status      # 输出 FINGERPRINT=SHA256:...
w4_hostkey_cycle.sh use-a       # 切到 host key A，重启 sshd，输出新 FINGERPRINT
w4_hostkey_cycle.sh use-b       # 切到 host key B，重启 sshd，输出新 FINGERPRINT
w4_hostkey_cycle.sh restore     # 恢复测试前原 key，重启 sshd，输出 FINGERPRINT
```

约束：

- w4 测试期间独占；脚本自身先备份原 `/etc/ssh/ssh_host_*` 和当前指纹；
- TB 会在 `finally` 调 `restore`，并在客户端备份/恢复 `~/.ssh/known_hosts`；
- 只允许 22 端口（产品注册强制解析到 22）；
- fake daemon 由 TB 在 w4 上临时起，用于让第 5 步的命令/token/skill 都通过，从而把唯一失败点钉在 host-key mismatch；
- 先写 mismatch 场景（step 3 固化 A → 切 B → step 5 必须 ERROR 且 registry 零写入），再写 update 后重探测场景。

脚本落地后，TB 命名为 `test/live/registration/registration_hostkey_rotation_tb.py`，仍按六步 + 证据 JSON 的格式移交。
