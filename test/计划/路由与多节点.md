# 测试计划 · 路由与多节点（五 role / 忠实投送 / 拓扑）

## 目标
五接口各自落到配置 role 的主机/账号；跨机、混合 local/remote、显式 jump/proxy、同 endpoint 多 role 均不串台；bridge 忠实投送。

## 流程（纲领）
1. **五 role 跨机**：daemon/gui@wsl，command/file/spectre@vps，逐接口回传 `hostname` 证据（E5）；
2. **混合模式**：daemon/command/file=local，gui/spectre=remote（E6）及反置组合；
3. **显式 jump/proxy**：role 显式 `jump_host/jump_user`、`ssh.default.proxy`（SOCKS5）与"config 内 ProxyJump"两种路由分别验证；
4. **同 endpoint 复用**：多 role 同 host/user 只建一条连接；同 token 多 endpoint 各一条；
5. **忠实投送**：file.root 指向异机/不可见路径 → 只报目标侧结果，不自行改写或迁移；不校验 role 是否同机。

## 预计响应
- 每接口返回证据=其 role 主机名，互不串台；
- local role 零 SSH 连接；remote 连接按 endpoint 去重（每 token 每 endpoint 一条）；
- 显式 jump 与 config 跳板两种路由结果一致；
- 异机/不可见路径 → `kind=path`/目标侧错误，无"合并/共享"行为。

## 环境
E5/E6、E10/E11（glis 客户端）、jump/proxy 用本机→wsl（config jump）与显式 jump 对照。

## 判据
五接口 × 五 role 落点矩阵全对；连接计数符合"每 token 每 endpoint 一条"。
