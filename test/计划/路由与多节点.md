# 路由与多节点（五 role / 忠实投送）

> 覆盖目标：TG2；环境 E5/E6/E10/E11
> 判定粒度：每个测试项都将由对应 TB 完整执行一次；本文件只定"测什么、怎么测、通过标准是什么"，具体代码归 `test/` 与 `test/tb/`。

### 1. 单机五 role

- **测试目标**：五 role 同 host/user 解析为同一 endpoint
- **测试流程**：单机配置下逐接口调用并统计连接数
- **预计响应**：每 token 每 endpoint 一条 SSH 连接

### 2. 五 role 跨机

- **测试目标**：daemon/gui@wsl，command/file/spectre@vps
- **测试流程**：E5 逐接口回传 hostname
- **预计响应**：各接口落点=其 role 主机，互不串台

### 3. local/remote 混合

- **测试目标**：daemon/command/file=local、gui/spectre=remote 及反置
- **测试流程**：E6 两组配置各一遍
- **预计响应**：local role 零 SSH；remote 落点正确

### 4. 同 endpoint 复用

- **测试目标**：多 role 同 host/user 共用连接
- **测试流程**：同 endpoint 多 role 并发调用
- **预计响应**：连接数为 1，无重复握手

### 5. 同 token 多 endpoint

- **测试目标**：不同 endpoint 各建连接
- **测试流程**：跨机配置并发调用
- **预计响应**：连接数=endpoint 数，无串用

### 6. 忠实投送

- **测试目标**：异机/不可见路径只报目标侧结果
- **测试流程**：file.root 指向不可见路径
- **预计响应**：kind=path 或目标侧错误；无改写、无迁移、无合并

### 7. 显式 jump 路由

- **测试目标**：role 显式 jump_host/jump_user
- **测试流程**：显式 jump 配置调用
- **预计响应**：命令落在 jump 后目标；身份/账号正确

### 8. proxy 路由

- **测试目标**：ssh.default.proxy（SOCKS5）
- **测试流程**：proxy 配置调用
- **预计响应**：经代理可达；endpoint key 含 proxy 原文

### 9. config jump 与显式 jump

- **测试目标**：两种路由等价/显式优先
- **测试流程**：同一目标两种配置对照
- **预计响应**：结果一致；显式覆盖 config

### 10. 端口/账号随 role

- **测试目标**：daemon_port/local_port 只作用于 daemon role
- **测试流程**：异 role 配置各自端口
- **预计响应**：端口不串；local daemon 的 local_port=daemon_port
