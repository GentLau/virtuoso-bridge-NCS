# 运维生命周期

> 覆盖目标：多用户设计 §11；环境 L2/E1/E3
> 判定粒度：每个测试项都将由对应 TB 完整执行一次；本文件只定"测什么、怎么测、通过标准是什么"，具体代码归 `test/` 与 `test/tb/`。

### 1. update 白名单

- **测试目标**：白名单内改、外拒绝
- **测试流程**：改各类字段
- **预计响应**：白名单成功；白名单外拒绝

### 2. update 原子覆盖

- **测试目标**：副本修改整体校验原子替换
- **测试流程**：update 并发
- **预计响应**：无半成品；新值一致

### 3. update 关缓存

- **测试目标**：改后关该 token 连接
- **测试流程**：update 后调用
- **预计响应**：下次调用重建连接

### 4. remove 本机解绑

- **测试目标**：remove 非远端吊销
- **测试流程**：remove 后连远端
- **预计响应**：本机无路由；远端仍接受原 token

### 5. 远端吊销

- **测试目标**：RBStop+删部署
- **测试流程**：执行吊销
- **预计响应**：token 完全失效

### 6. 跨进程写锁

- **测试目标**：并发写不丢更新
- **测试流程**：两进程同写
- **预计响应**：后写者基于最新文件

### 7. load-once

- **测试目标**：运行期不频繁 IO
- **测试流程**：运行期统计读盘
- **预计响应**：仅启动读一次

### 8. 指纹更新

- **测试目标**：机器重装显式 update
- **测试流程**：新指纹 update
- **预计响应**：未确认前拒绝；更新后恢复

### 9. 删除失败一致性

- **测试目标**：以 registry 为准
- **测试流程**：远端删除失败
- **预计响应**：registry 解绑仍成立、不做远端回滚
