# 测试计划 · 等价性

## 目标
三类等价：local≡remote、两条 Windows 客户端（本机≡glis）等价、openssh≡paramiko 等价（后者在 ProxyJump 验证通过前标 PENDING）。

## 流程（纲领）
1. **local≡remote**：同一业务序列（skill/命令/上传/下载/组合链）分别在 local 与 remote 配置执行（E3 vs E1/E4）；
2. **客户端等价**：同一序列分别在本机与 glis 上发起（E7），目标与用户一致；
3. **backend 等价**：同一目标分别用 openssh 与 paramiko 执行（E1/E2），先直连（vps）再经 jump（wsl-gent）。

## 预计响应
- 三类等价的结果集与摘要完全一致；仅延迟/时序可不同；
- 文件往返 sha256 一致；错误分类一致；
- paramiko 经 jump 未验证前，该组合只在报告中标注，不参与准出。

## 环境
E3/E4、E7（本机 vs glis）、E1/E2（backend）。

## 判据
每类等价有"同序列双跑"的证据与差异清单（只允许时序差异）。
