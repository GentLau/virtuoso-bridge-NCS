# 测试计划 · 等价性

## 目标
local≡remote、本机≡glis 双 Windows 客户端、openssh≡paramiko 三类等价（paramiko 经 jump 验证前 PENDING）。

## 流程（纲领）
1. **local≡remote**：同一序列分别在 local 与 remote 执行（E3 vs E1/E4）；
2. **客户端等价**：同一序列分别在本机与 glis 发起（E7），目标/用户一致；
3. **backend 等价**：同一目标 openssh 与 paramiko 各跑（E1/E2）；先直连 vps 再经 jump wsl-gent；
4. **大文件等价**：≥10MB 文件在两 backend 的往返 sha256 一致；
5. **max_sessions**：paramiko 下并发数等于 `max_sessions` 时的行为与 openssh 的 channel 拒绝等价。

## 预计响应
- 三类等价结果集与摘要一致，仅延迟/时序可不同；
- 文件往返 sha256 一致；错误分类一致；
- paramiko 经 jump 未验证前仅报告不参与准出。

## 环境
E3/E4、E7、E1/E2。

## 判据
每类等价有"同序列双跑"证据与差异清单（只允许时序差异）。
