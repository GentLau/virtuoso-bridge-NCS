# 功能正确性（五接口）

> 覆盖目标：TG1/TG7/TG8；环境 E1/E3/E11
> 判定粒度：每个测试项都将由对应 TB 完整执行一次；本文件只定"测什么、怎么测、通过标准是什么"，具体代码归 `test/` 与 `test/tb/`。

### 1. Skill 基础语义

- **测试目标**：正确、错误、nil 三类 SKILL 表达式各返回符合语义的结构化结果
- **测试流程**：L0 解析；L1 协议级假 daemon；L3 真机跑 RBDToken、算术、printf
- **预计响应**：success/error 与输出值正确；nil 可表达；错误不落为 command 类错误

### 2. Skill wire 协议

- **测试目标**：STX/NAK/RS 帧、JSON payload、token 字段、一连接一请求一响应、EOF
- **测试流程**：L1 假 daemon 逐字节收发；错帧、非 JSON、缺 token 各一例
- **预计响应**：合法请求以 02/15+JSON+1e 返回；非法帧按错误返回；连接随响应关闭

### 3. Skill 超时

- **测试目标**：timeout=None 默认 30s；显式 0/极小值触发超时
- **测试流程**：注入慢 SKILL；显式大值验证正常完成
- **预计响应**：超时返回固定文本 SKILL execution timed out；预算内完成则返回结果

### 4. RunCommand 基础

- **测试目标**：stdout/stderr/exitcode 分通道透传
- **测试流程**：echo、printf 到 stderr、exit 7 各一例
- **预计响应**：三字段与远端一致；rc=7 保持 kind=command

### 5. RunCommand 串行

- **测试目标**：同一 token 命令严格按提交顺序
- **测试流程**：连续多条带顺序标记的命令
- **预计响应**：输出顺序=提交顺序，无乱序

### 6. RunCommand 并行

- **测试目标**：parallel=True 走独立通道
- **测试流程**：两条耗时命令同时提交，记录起止时间
- **预计响应**：执行区间重叠；不共享 cwd/env；占 channel 预算

### 7. RunCommand 超时

- **测试目标**：超时命令返回保留码
- **测试流程**：sleep 超过预算
- **预计响应**：kind=timeout / rc=124；远端进程被终止

### 8. File 单文件上传

- **测试目标**：上传成功且内容一致
- **测试流程**：本地固定字节文件上传到 file root
- **预计响应**：rc=0；远端字节一致；临时文件清理

### 9. File 单文件下载

- **测试目标**：下载成功且内容一致
- **测试流程**：远端固定文件下载到本地
- **预计响应**：rc=0；本地 sha256 与远端一致

### 10. File 往返校验

- **测试目标**：单文件双向 sha256
- **测试流程**：上传→下载→比对摘要；再篡改远端触发失败路径
- **预计响应**：两向 sha 一致；不一致返回 kind=checksum / sha256 mismatch

### 11. File recursive 目录

- **测试目标**：目录树整体传输
- **测试流程**：含子目录/空目录的树上传与下载
- **预计响应**：树结构完整一致；不逐文件校验

### 12. File 边界输入

- **测试目标**：空文件/大文件/二进制/类型不符/源缺失/目标覆盖/只读目标
- **测试流程**：分别构造以上输入
- **预计响应**：空与大文件 sha 一致；二进制无损；类型不符/源缺失 kind=path；覆盖无半成品；只读目标返回目标侧错误

### 13. File 路径解析

- **测试目标**：绝对/相对/~ 三种 remote_path
- **测试流程**：三种路径各上传一次；非法路径一例
- **预计响应**：绝对原样；相对按 file root；~ 按该 role 账号展开；越界/非法 kind=path

### 14. GUI 命令执行

- **测试目标**：gui role 一次性命令
- **测试流程**：hostname 等命令连发两次（remote）
- **预计响应**：返回 gui 主机证据；两次调用无 cwd/env 继承

### 15. Spectre 命令执行

- **测试目标**：spectre role 一次性命令
- **测试流程**：hostname、spectre -V 连发两次（remote）
- **预计响应**：返回 spectre 主机证据；无状态继承

### 16. GUI/Spectre local 侧

- **测试目标**：local role 等价语义
- **测试流程**：本机/glis Windows local role 各一遍
- **预计响应**：与 remote 结果一致；不产生 SSH 连接
