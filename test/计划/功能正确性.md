# 测试计划 · 功能正确性（五接口与边界输入）

## 目标
验证五接口参数与返回语义符合架构 §4；文件语义符合 §4.5；覆盖边界输入。

## 流程（纲领）
1. **Skill**：函数级解析 → 协议级假 daemon → 真机 `RBDToken`/算术/`printf`/写日志表达式；`nil` 返回、SKILL 求值错误各一例；验证 STX/NAK/RS 帧、JSON payload、一连接一请求一响应、EOF。
2. **RunCommand**：`echo` 冒烟 → 串行依赖顺序 → `parallel=True` → 非零退出码透传 → 超时。
3. **File**：单文件往返 sha256 → `recursive` 目录树 → 空文件/大文件/二进制内容 → 类型不符/源缺失/目标已存在/目标只读 → local 与 remote 对照。
4. **GUI/Spectre**：各自 role 上 `hostname` 类一次性命令（remote 与 local 各一遍）；连续调用无状态继承。

## 边界输入（必测）
- `timeout`：缺省=30s；显式 0/极小值 → `kind=timeout`；大值 → 正常完成；
- 路径：`remote_path` 绝对路径、相对路径（按 file root 解析）、`~` 开头；非法/越界输入 → `kind=path`；
- 文件：空文件、≥10MB 大文件、非 UTF-8 二进制，往返 sha256 一致；
- 命令：非零退出码原样透传（`kind=command`）；stdout/stderr 分通道正确；
- Skill：返回 `nil`/非字符串值按协议序列化，不崩溃。

## 预计响应
- Skill：正确表达式 `status=success` 且输出符合 SKILL 语义；错误表达式 `status=error`；`nil` 可表达；
- 命令：串行保持提交顺序；并行时间区间重叠；退出码原样；超时 → `kind=timeout`/124；
- 文件：单文件双向 sha256 一致；目录整树一致（不逐文件校验）；类型不符/源缺失 → `kind=path`；覆盖无半成品；只读目标 → `path` 或目标侧错误；local≡remote；
- GUI/Spectre：返回目标 role 主机证据；连续调用无 cwd/env 继承；local 侧同样成立；占用 channel 预算。

## 环境
L0/L1/L2 全环境；L3/TB 用 E1、E3、E11（Windows local role）。

## 判据
每条"输入→期望→实测"有记录；无跳过项。
