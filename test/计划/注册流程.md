# 测试计划 · 注册流程、reservation 与输入安全

## 目标
六步状态机、缺省端口时序、reservation 互斥/回收/TOCTOU、失败不留半成品、注册与使用解耦；输入安全与首信任符合配置一览 §5。

## 流程（纲领）
1. **正常链**：申请→本地校验→探测（固化 expected_* 与绝对 role.root）→部署→第五步连通→落盘；
2. **输入安全**：user/token 字符集；Windows 设备名（CON/PRN/NUL/COM1-9/LPT1-9）、大小写不敏感查重、`..`/绝对路径越界；`mode.default` 缺失；local role 显式提交 host/user 等非法字段；
3. **首信任**：known_hosts 匹配→记录；显式指纹→校验后记录；两者皆无→失败；同 endpoint 多 role 指纹一致；
4. **端口时序**：显式端口查重；缺省端口锁内分配（local_port 第二步、远端 daemon_port 第三步）；local daemon 的 `local_port=daemon_port`；异主机同号允许；
5. **失败注入**：参数错/重名/端口冲突/ssh 不可达/探测不满足/部署失败/第五步 NAK/指纹不匹配，逐项回退且 registry 零写入；
6. **重试与清理**：第五步失败重试；覆盖式重部署（ramic/setup/status 重新投送）；cancel；第四步前 TOCTOU 复核、冲突重分配一次；
7. **等待续租**：>宽限等待时心跳续租；pid 失效+超宽限回收；pid 复用已知限制；
8. **解耦**：注册结束后无 ssh 隧道/mux master/控制 socket；spectre 探测失败仅 WARNING 不阻断。

## 预计响应
- 任一必检失败 → 对应步骤失败，第六步前 registry 零写入；
- 探测后：role.root=绝对路径、root.default=null、expected_* 固化；
- 非法输入按 §5 拒绝；首信任三优先级按序成立；
- 同主机同端口拒绝、异主机同号允许、local daemon 端口作用域=本机；
- 等待期不被误回收；注册结束零残留；`cancel()` 释放 reservation。

## 环境
L2 全流程；L3/TB E1/E3；并发注册 E3/E8。

## 判据
多用户设计 §3.2 每步"预测目标/失败合同"与配置一览 §4/§5 逐行对应。
