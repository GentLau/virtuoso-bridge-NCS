# 测试计划 · CDS.log 增量返回

## 目标
验证增量 `[start,end)` 字节正确、`off` 源头零获取、分级过滤、限长降级、固定 warning、无注入。

## 流程（纲领）
1. **字节级**：每请求前后 `stat` 文件长度，请求后用 `dd` 读真实区间，与返回 `log` 逐字节比较（写日志/空输出交替）；
2. **四档**：all/warn/error/off 各跑写日志与空输出；
3. **限长**：构造超长输出，验证"全量→仅 error→头尾截断+降级提示"的顺序；
4. **off 源头**：断言 IL 不 flush/不 fileLength/不第二帧，daemon 不读文件；
5. **不可读**：改路径/删除文件，验证 `log=""` + 固定 warning `CDS.log unavailable: <reason>`；
6. **无注入**：检查 CDS.log 无桥写入的任何行。

## 预计响应
- 返回 `log` 与真实文件区间逐字节一致（含降级时的提示行）；
- `off` → `log=""`、无 warning、零文件访问；
- 非 off 且读不到 → `log=""` + 固定 warning，Skill 结果不受影响；
- CDS.log 桥注入行数 = 0。

## 环境
E1（真实 Virtuoso）；L0 用假文件做降级单测。

## 判据
分级/限长/降级规则与日志返回设计标准逐条对应；字节比对 100%。
