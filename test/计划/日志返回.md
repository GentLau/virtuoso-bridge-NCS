# 测试计划 · CDS.log 增量返回

## 目标
增量 `[start,end)` 字节正确、off 源头零获取、分级过滤、限长降级、固定 warning、轮转/异常、无注入、多用户独立。

## 流程（纲领）
1. **字节级**：每请求前后 `stat`，用 `dd` 读真实区间与返回 `log` 逐字节比较（写日志/空输出交替）；
2. **四档**：all/warn/error/off × 写日志/空输出；
3. **限长**：超长输出 → "全量→仅 error→头尾截断+降级提示"；`log_max_bytes` 取极小值；
4. **off 源头**：IL 不 flush/不 fileLength/不第二帧，daemon 不读文件；
5. **异常**：文件轮转/清空（`size<start` → 从 0 读）、删除/不可读、第二帧超时（第一帧优先、`log=""`+warning）；
6. **无注入**：CDS.log 桥注入行数=0；
7. **多用户**：多个 user 的日志互不串。

## 预计响应
- 返回 `log` 与真实文件区间逐字节一致（含降级提示行，提示行不受限长约束）；
- `off` → `log=""`、无 warning、零文件访问；
- 非 off 且读不到/第二帧缺失 → `log=""` + 固定 warning `CDS.log unavailable: <reason>`，Skill 结果不受影响；
- 轮转/截断按"从 0 读可读多少算多少"；CDS.log 注入行数=0；每 user 各自独立。

## 环境
E1 真机；L0 假文件降级单测。

## 判据
日志返回设计标准逐条对应；字节比对 100%。
