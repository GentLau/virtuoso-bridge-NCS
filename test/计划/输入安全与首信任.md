# 测试计划 · 输入安全与首信任

## 目标
注册输入按配置一览 §5 校验；host-key 首信任三优先级；token 生命周期约束。

## 流程（纲领）
1. **user**：字符集 `^[A-Za-z0-9][A-Za-z0-9._-]{0,63}$`；禁止 `/`、`\`、`..`、绝对路径；Windows 大小写不敏感查重与保留设备名（CON/PRN/AUX/NUL/COM1-9/LPT1-9 及带扩展名）拒绝；
2. **token**：自动生成与手动 `^[A-Za-z0-9._-]{1,64}$`；碰撞重生成一次；终生不变、删除用户才轮换；
3. **首信任**：① known_hosts 匹配→记录；② 显式指纹→校验后记录；③ 都无→失败；spectre 例外（缺失/失败仅 WARNING、指纹留空）；
4. **非法字段**：`mode.default` 缺失；local role 显式 host/user/jump/proxy → 参数错误；未知字段 → 拒绝（extra=forbid）；空串视为未提供。

## 预计响应
- 合法输入通过；每类非法输入被对应理由拒绝且零副作用；
- 首信任三优先级按序成立；spectre 例外不阻断；
- token 只用于路由/校验，不进入路径段。

## 环境
L0/L2；L3 E1/E3。

## 判据
配置一览 §5 与 §4.1/§4.2 逐行对应。
