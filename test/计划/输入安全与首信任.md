# 输入安全与首信任

> 覆盖目标：配置一览 §5；环境 L0/L2/E1/E3
> 判定粒度：每个测试项都将由对应 TB 完整执行一次；本文件只定"测什么、怎么测、通过标准是什么"，具体代码归 `test/` 与 `test/tb/`。

### 1. user 字符集

- **测试目标**：合法/非法 user
- **测试流程**：非法字符集各例
- **预计响应**：合法通过；非法按规则拒绝

### 2. Windows 设备名/大小写

- **测试目标**：CON/PRN/NUL/COM/LPT 与大小写
- **测试流程**：设备名与 Alice/alice
- **预计响应**：拒绝保留名；大小写视为同一

### 3. 路径 containment

- **测试目标**：禁止 / 与反斜杠 与 .. 与绝对路径
- **测试流程**：越界 user 申请
- **预计响应**：拒绝注册

### 4. token 规则

- **测试目标**：字符集/碰撞/终生
- **测试流程**：非法 token/碰撞
- **预计响应**：非法拒绝；碰撞重生成一次；轮换=删用户重注册

### 5. 首信任三优先级

- **测试目标**：known_hosts→显式→失败
- **测试流程**：三情形各一例
- **预计响应**：按序成立；两者皆无=失败

### 6. spectre 指纹例外

- **测试目标**：缺失/不匹配仅 WARNING
- **测试流程**：spectre 无指纹
- **预计响应**：WARNING、指纹留空、不阻断

### 7. 非法字段

- **测试目标**：local 连接字段/未知字段/空串
- **测试流程**：各非法输入
- **预计响应**：local 显式连接字段=参数错误；未知字段拒绝；空串=未提供
