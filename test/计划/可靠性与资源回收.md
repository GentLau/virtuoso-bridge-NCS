# 可靠性与资源回收

> 覆盖目标：TG10/TG11；环境 L2/E1/E3
> 判定粒度：每个测试项都将由对应 TB 完整执行一次；本文件只定"测什么、怎么测、通过标准是什么"，具体代码归 `test/` 与 `test/tb/`。

### 1. 隧道失效重建

- **测试目标**：杀隧道后自愈
- **测试流程**：杀 ssh -N 后继续 skill
- **预计响应**：自动重建、上层无感

### 2. daemon 失效重连

- **测试目标**：杀 daemon 结构化失败→重启重连
- **测试流程**：杀 daemon / 重启 daemon
- **预计响应**：期间明确失败；重启后恢复

### 3. shell 投递前死亡

- **测试目标**：透明重建
- **测试流程**：投递前杀 shell
- **预计响应**：新 shell 执行成功

### 4. shell 投递后死亡

- **测试目标**：不重发
- **测试流程**：投递后杀 shell
- **预计响应**：unknown-effect；副作用计数=1

### 5. shell 重建状态

- **测试目标**：不恢复旧 cwd/env
- **测试流程**：旧 shell cd 后重建
- **预计响应**：新 shell 初始 cwd/env

### 6. mux 卡死

- **测试目标**：探测降级直连
- **测试流程**：构造卡死 master
- **预计响应**：探测后降级直连成功

### 7. ControlPath 隔离

- **测试目标**：token 间不共享
- **测试流程**：双 token 同主机
- **预计响应**：ControlPath 不同

### 8. close 只拆本 token

- **测试目标**：关闭不影响他人
- **测试流程**：close 一个 token
- **预计响应**：另一 token 连接存活

### 9. 资源盘点

- **测试目标**：每轮零残留
- **测试流程**：注册/压测/异常退出后清点
- **预计响应**：进程/端口/socket/reservation/临时文件=0

### 10. 同种子复现

- **测试目标**：结果与计数一致
- **测试流程**：固定种子重跑
- **预计响应**：结果集一致
