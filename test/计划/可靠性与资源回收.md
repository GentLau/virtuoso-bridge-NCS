# 测试计划 · 可靠性与资源回收

## 目标
投递前失效自愈、投递后不重发；shell 重建不恢复旧状态；ControlPath 按 token 隔离；close 只影响本 token；每轮零残留；同种子可复现。

## 流程（纲领）
1. **隧道失效**：杀 `ssh -N` → 自动重建；
2. **daemon 失效**：杀 daemon → 结构化失败 → 重启 → 重连；
3. **shell 失效**：投递前杀 → 透明重建；投递后杀 → `unknown-effect` 不重发；
4. **shell 重建语义**：重建后为全新登录 shell（cwd/env 不恢复旧会话状态）；
5. **mux 卡死**：遗留/卡死 ControlMaster → 探测降级直连；
6. **token 隔离**：两个 token 同主机，ControlPath 不同；close 一个 token 不影响另一个的连接；
7. **回收盘点**：注册/压测/异常退出各一轮，清点 ssh 进程/端口/socket/reservation/临时文件；
8. **复现性**：固定种子重跑结果集与计数一致。

## 预计响应
- 投递前失效自愈且调用方无感；投递后失效不重发；
- 重建后无旧 cwd/env；mux 卡死自动降级；
- token 间 ControlPath/连接隔离，close 只拆自己；
- 每轮盘点 0 残留；同种子结果一致。

## 环境
L2 mock + 真机 E1/E3；mux 用 Windows openssh 客户端。

## 判据
故障注入清单与恢复证据一一对应；盘点表为 0。
