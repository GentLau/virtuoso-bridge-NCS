# CDS.log 增量返回

> 覆盖目标：TG7；环境 E1/L0
> 判定粒度：每个测试项都将由对应 TB 完整执行一次；本文件只定"测什么、怎么测、通过标准是什么"，具体代码归 `test/` 与 `test/`。

### 1. 增量字节一致

- **测试目标**：返回 log 与 [start,end) 逐字节一致
- **测试流程**：每请求前后 stat 文件长度，请求后用 dd 读真实区间比对
- **预计响应**：100% 一致

### 2. off 源头

- **测试目标**：off 不读不 flush 不第二帧
- **测试流程**：off 档写日志请求
- **预计响应**：log=""、无 warning、零文件访问

### 3. 分级过滤

- **测试目标**：all/warn/error 三档
- **测试流程**：三档各写入 o/w/e 级别行
- **预计响应**：保留行符合级别判定

### 4. 限长降级

- **测试目标**：全量→仅 error→头尾截断
- **测试流程**：超长输出
- **预计响应**：降级顺序与提示行符合标准

### 5. 极小限长

- **测试目标**：log_max_bytes 极小
- **测试流程**：max_bytes=1
- **预计响应**：按字节裁剪+降级提示

### 6. 固定 warning

- **测试目标**：读不到返回固定文本
- **测试流程**：删文件/改路径
- **预计响应**：log="" + CDS.log unavailable 前缀；Skill 结果照常

### 7. 轮转/截断

- **测试目标**：size<start 从 0 读
- **测试流程**：请求中途清空日志
- **预计响应**：可读多少算多少，不报错

### 8. 第二帧超时

- **测试目标**：第一帧优先
- **测试流程**：注入第二帧超时
- **预计响应**：log="" + 固定 warning，Skill 结果优先返回

### 9. 无注入

- **测试目标**：桥不写 CDS.log
- **测试流程**：多轮写日志请求后检查文件
- **预计响应**：桥注入行数=0

### 10. 多用户独立

- **测试目标**：每 user 日志隔离
- **测试流程**：2 user 并发写日志
- **预计响应**：各自 log 正确、无串
