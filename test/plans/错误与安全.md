# 错误合同与安全

> 覆盖目标：TG8/TG9；环境 L0/L1/L2/E1/E3
> 判定粒度：每个测试项都将由对应 TB 完整执行一次；本文件只定"测什么、怎么测、通过标准是什么"，具体代码归 `test/` 与 `test/`。

### 1. kind=timeout

- **测试目标**：124 保留码
- **测试流程**：慢命令/skill 超时
- **预计响应**：kind=timeout / rc=124 / 超时说明

### 2. kind=transport

- **测试目标**：255 与 VB-TRANSPORT 前缀
- **测试流程**：断连/连不上
- **预计响应**：kind=transport / rc=255 / 前缀正确

### 3. kind=path

- **测试目标**：VB-PATH-NOT-VISIBLE 前缀
- **测试流程**：源缺失/不可见
- **预计响应**：kind=path / 前缀正确

### 4. kind=unknown-effect

- **测试目标**：投递后不重发
- **测试流程**：投递后杀 shell
- **预计响应**：kind=unknown-effect / 前缀正确；远端副作用计数=1

### 5. kind=rejected

- **测试目标**：容量拒绝可重试
- **测试流程**：打满预算
- **预计响应**：kind=rejected / 对应文本

### 6. kind=checksum

- **测试目标**：sha 不一致
- **测试流程**：篡改远端文件
- **预计响应**：kind=checksum / sha256 mismatch

### 7. kind=invalid-token

- **测试目标**：两形态固定文本
- **测试流程**：unknown token 的 Skill 与 CommandResult
- **预计响应**：errors 含 invalid token / stderr=invalid token

### 8. 重试上限

- **测试目标**：无副作用阶段最多 3 次
- **测试流程**：握手失败计数
- **预计响应**：≤3 次总尝试；副作用阶段不重试

### 9. 错 token 零接触

- **测试目标**：NAK 且 SKILL 零接触
- **测试流程**：错 token 请求
- **预计响应**：NAK invalid token；daemon 日志无 SKILL 痕迹

### 10. 指纹安全

- **测试目标**：不匹配 ERROR、漂移 WARNING
- **测试流程**：改指纹/改 banner
- **预计响应**：host-key 不匹配 ERROR；hostname/user 漂移 WARNING

### 11. 同 endpoint 指纹一致

- **测试目标**：多 role 同 endpoint 指纹
- **测试流程**：两 role 不同指纹注册
- **预计响应**：拒绝注册

### 12. 部署与授权

- **测试目标**：目录 700、load 打印、banner 不回显
- **测试流程**：检查目录权限与输出
- **预计响应**：目录 700；load 打印 token 本身；banner 无 token

### 13. token 不进路径

- **测试目标**：路径只用用户名
- **测试流程**：检查 registry/部署路径
- **预计响应**：无 token 段
