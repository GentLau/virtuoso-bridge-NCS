# 注册流程与内存 reservation

> 覆盖目标：最新 spec `多用户与注册 v17` / `中层配置文档 v24`；环境 L2/E1/E3/E8
> 判定粒度：每个测试项都要有一次可复算证据；本文件只定义“测什么、怎么测、通过标准”。

### 1. 第一步参数

- **测试目标**：`mode.default`、`user` 等必填项缺失/非法即参数错误
- **测试流程**：缺字段、非法 user/token、local role 提交 host/user
- **预计响应**：结构化参数错误，零副作用

### 2. 第二步本地校验

- **测试目标**：user/token/显式端口查重，内存候选建立
- **测试流程**：重名、重 token、同 daemon 主机同端口、异主机同号
- **预计响应**：冲突拒绝；异主机同号允许；只写进程内存，不产生文件

### 3. 第三步探测

- **测试目标**：五 role 命令可用性、SSH 端口 22、host-key、root 可写
- **测试流程**：每 role 顺序执行命令/端口/root 探测；spectre 失败仅 WARNING
- **预计响应**：四个业务 role 任一失败为 ERROR；spectre 失败不阻断

### 4. 第三步固化

- **测试目标**：`expected_*` 与各 role 绝对 root
- **测试流程**：探测后检查内存候选，再提交
- **预计响应**：fingerprint/hostname/user 固化；root 为绝对路径、`root.default=null`

### 5. 缺省端口时序

- **测试目标**：local 联合端口、remote daemon/local 端口分配
- **测试流程**：缺省端口的两条并发内存注册
- **预计响应**：第二步/第三步在进程内 candidate table 分配；不撞端口

### 6. 第四步部署

- **测试目标**：文件集与 setup_path
- **测试流程**：部署后检查 `role.daemon.root`
- **预计响应**：`ramic/setup/status` 齐全；setup_path 是 daemon 侧绝对路径

### 7. 第五步连通性

- **测试目标**：daemon 可达、token、双冒烟、指纹、banner/user
- **测试流程**：逐项注入不匹配
- **预计响应**：必检 ERROR；banner/user 漂移 WARNING；全部通过才可提交

### 8. 第六步落盘

- **测试目标**：final re-check + schema shape + 原子写
- **测试流程**：提交前制造端口/registry 冲突和非法 shape
- **预计响应**：冲突或 shape 错误拒绝；成功时只有 registry 文件变化

### 9. 每步失败回退

- **测试目标**：前五步任何失败 registry 零写入
- **测试流程**：逐步失败注入
- **预计响应**：无半成品条目，无临时文件残留

### 10. 重试与 TOCTOU

- **测试目标**：第四步前复核端口，冲突允许重分配一次
- **测试流程**：探测后占用端口，再进入 deploy
- **预计响应**：能替代则重分配；仍冲突则拒绝

### 11. 内存 reservation 互斥

- **测试目标**：同一注册服务进程内不撞 user/token/端口
- **测试流程**：共享 `ReservationTable` 的两条 flow 并发推进
- **预计响应**：后到者按冲突被拒；不产生 `registry.reservation`

### 12. 内存候选生命周期

- **测试目标**：候选只活在注册进程内
- **测试流程**：apply/validate/probe/deploy 后取消或退出
- **预计响应**：候选消失；没有跨进程租约、pid 续租或宽限回收

### 13. cancel 与会话断开

- **测试目标**：取消/异常退出放弃全部内存候选
- **测试流程**：cancel / flow 丢弃 / 服务重启
- **预计响应**：候选被释放；registry 无条目；本地无 reservation 文件

### 14. 注册与使用解耦

- **测试目标**：注册结束零残留
- **测试流程**：成功、失败、取消三条路径做资源盘点
- **预计响应**：除 registry 与远端部署文件外，无 SSH 进程/隧道/控制 socket/临时文件

### 15. spectre 例外

- **测试目标**：spectre 探测失败不阻断
- **测试流程**：删除/替换 spectre 可执行路径
- **预计响应**：WARNING；`root`/`expected_fingerprint`/`bin` 提交为 null；其余 role 照常

### 16. local daemon

- **测试目标**：`local_port=daemon_port`，端口作用域本机
- **测试流程**：local daemon 注册
- **预计响应**：两者相等；本机冲突被拒
