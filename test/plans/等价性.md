# 等价性

> 覆盖目标：TG6；环境 E3/E4/E7/E1/E2
> 判定粒度：每个测试项都将由对应 TB 完整执行一次；本文件只定"测什么、怎么测、通过标准是什么"，具体代码归 `test/` 与 `test/`。

### 1. local=remote 五接口

- **测试目标**：同序列结果一致
- **测试流程**：同序列在 local 与 remote 各跑一遍
- **预计响应**：结果集与摘要一致，仅时序可不同

### 2. 本机=glis 客户端

- **测试目标**：两条 Windows 客户端等价
- **测试流程**：同序列在本机与 glis 各跑一遍
- **预计响应**：结果一致

### 3. openssh=paramiko 直连

- **测试目标**：后端切换结果一致
- **测试流程**：vps 直连双后端各跑一遍
- **预计响应**：结果集/摘要/错误分类一致

### 4. openssh=paramiko jump

- **测试目标**：jump 链路等价
- **测试流程**：wsl-gent 双后端各跑一遍
- **预计响应**：PENDING：链路验证前不参与准出

### 5. 大文件等价

- **测试目标**：≥10MB 往返
- **测试流程**：双后端各传一次
- **预计响应**：sha256 一致

### 6. 错误分类等价

- **测试目标**：同一故障双后端分类一致
- **测试流程**：断连/路径缺失注入
- **预计响应**：kind 与保留码一致

### 7. max_sessions 等价

- **测试目标**：paramiko 并发上限语义
- **测试流程**：并发数=max_sessions
- **预计响应**：与 openssh 的 channel 拒绝同义、可重试
