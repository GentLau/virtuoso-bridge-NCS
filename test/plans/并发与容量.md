# 并发与容量

> 覆盖目标：TG4/TG5；环境 E2/E4/E8/E9
> 判定粒度：每个测试项都将由对应 TB 完整执行一次；本文件只定"测什么、怎么测、通过标准是什么"，具体代码归 `test/` 与 `test/`。

### 1. 线程池预算

- **测试目标**：thread_pool_size 超限
- **测试流程**：打满线程池再发一请求
- **预计响应**：thread pool exceeded、kind=rejected、不排队

### 2. token 最大通道数

- **测试目标**：`runtime.channel_budget` 在 token 内所有 endpoint 合计后超限
- **测试流程**：打满 token 通道再发并行/文件/GUI/Spectre
- **预计响应**：`channel budget exceeded`、`kind=rejected`

### 2.1 endpoint max_sessions

- **测试目标**：多 role 同 endpoint 共享计数，有效上限取 role 配置最小值
- **测试流程**：同 endpoint 并发到 max_sessions 和 max_sessions+1
- **预计响应**：上限内成功；超限 `role max_sessions exceeded`

### 3. 拒绝文本区分

- **测试目标**：两种拒绝可区分
- **测试流程**：分别触发两预算
- **预计响应**：文本与来源一一对应

### 4. 拒绝重试

- **测试目标**：被拒立即重试直至成功
- **测试流程**：每 token 高频并发+重试
- **预计响应**：被接受集合 100% 正确；重试计数完整

### 5. 预算 token 隔离

- **测试目标**：一 token 打满不影响另一 token
- **测试流程**：双 token 同发
- **预计响应**：后者零排队

### 6. 同 token 多 endpoint 共享

- **测试目标**：线程预算与 channel 预算按 token 合计
- **测试流程**：跨 endpoint 并行打满
- **预计响应**：预算不随 endpoint 数量增加；endpoint 计数另计且取 role 最小值

### 7. 单 CIW 串行

- **测试目标**：同 token skill 串行
- **测试流程**：同 token 双 skill 计时
- **预计响应**：执行区间不重叠、顺序一致

### 8. 跨 CIW 并行

- **测试目标**：不同 token skill 并行
- **测试流程**：双 token 双 skill 计时
- **预计响应**：执行区间重叠

### 9. 命令串行/并行

- **测试目标**：默认串行、parallel 并行
- **测试流程**：顺序标记命令 + 并行计时
- **预计响应**：串行保序；并行区间重叠

### 10. 文件并行

- **测试目标**：多路上传/下载并行
- **测试流程**：N 路并发往返
- **预计响应**：全部 sha 一致

### 11. 校验不另占 channel

- **测试目标**：文件校验子命令在同一名额内
- **测试流程**：通道打满时触发校验
- **预计响应**：不产生额外拒绝

### 12. 同账号多用户隔离

- **测试目标**：同 SSH 账号多 user 不串
- **测试流程**：同账号 2 user 并发
- **预计响应**：命令流/返回/文件/日志互不串

### 13. 100+ 用户规模

- **测试目标**：自动路由 100+ 用户
- **测试流程**：注册 100 用户混合五接口
- **预计响应**：全部路由成功、零跨用户串扰

### 14. 组合服务链

- **测试目标**：上传→skill→命令→下载→sha
- **测试流程**：服务器侧组合服务并发
- **预计响应**：每链全部通过、sha 一致

### 15. 强靶机规模压力

- **测试目标**：100 用户自动路由和混合业务负载
- **测试流程**：WSL 100 fake daemon；Windows→WSL 100 remote 用户；混合 skill/命令/文件/GUI/Spectre，拒绝立即重试
- **预计响应**：全部请求最终正确；容量拒绝文本明确；压测后 ssh/隧道数不增长

### 16. local role 预算

- **测试目标**：local 计线程不计 channel
- **测试流程**：local role 打满两预算
- **预计响应**：线程拒绝出现、channel 不参与
