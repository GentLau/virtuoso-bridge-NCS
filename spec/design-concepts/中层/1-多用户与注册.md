# 多用户与注册

> 版本：Draft v23
> 日期：2026-09-15
> 状态：Normative（注册侧唯一口径）
> Supersedes：Draft v22（修改类路径用 user 定位，token 作校验凭证）
> 定位：本文只讲**注册**（六步法、授权、要填参数）与**注册表生命周期**；运行期路由与限流见[路由设计](3-路由设计.md)、[并发设计](2-并发设计.md)；字段与默认值的详细清单见[中层配置文档](../中层/add-中层配置文档.md)。

## 1. 总述与 token（授权）

- **注册表是唯一持久化**：本地一份 `registry.json`，`user` 为键；启动时导入一次到内存快照，此后运行期**不再读文件**。
- **注册与使用解耦**：六步注册结束后，除文件系统变更（registry + 远端部署文件）外不得残留隧道、SSH 进程或控制 socket。
- **token = 寻址键 + 授权票**：形式 `^[A-Za-z0-9._-]{1,64}$`（缺省自动生成）；终生有效、不轮换；轮换 = 删除用户重新注册。
- **授权 = 目视确认**：token 由客户端生成，部署时写入 il；用户在 CIW `load` 时 il 打印 token，用户目视比对一致即授权。
- **token 使用范围**：只用于路由与校验（注册表路由、daemon 比对、Skill 请求）；用户可读路径一律用唯一用户名，不用 token。
- **token 边界**：防 Skill 通道误连（连错会话/他人 daemon）；不承担 SSH 认证。`user` 只是路径名与注册表主键，不是安全凭证。

## 2. 要填参数（摘要）

必填项以[中层配置文档 §4](../中层/add-中层配置文档.md)为准，本节只列关键点：

- **必填**：`mode.default`（`local`/`remote`，不推断）、`user`；
- **条件必填**：每个 remote role 必须可解析出目标——`role.<name>.host/user` 或全局 `ssh.default.host/user`；
- **可选**：`token`（缺省生成）、`role.daemon.daemon_port/local_port`（缺省自动分配）、各 role 覆盖、`ssh.*`/`runtime.*`/`cdslog.*` 策略项；
- 非法字段、local role 的 host/user、未知字段一律拒绝（规则见[中层配置文档 §5](../中层/add-中层配置文档.md)）。

## 3. 六步注册法（核心）

### 3.1 流程与预测目标

**①申请 → ②本地校验 → ③探测 → ④部署 → ⑤连通性测试 → ⑥写注册表**；**前五步不写 registry**（`registry.json` 零写入，候选只存内存），第六步是唯一写盘点；未完成六步即放弃全部内存候选。

| 步 | 预测目标（可观察） | 不达成时 | 重试 |
|---|---|---|---|
| 1 申请 | 必填参数齐全（见 §2） | 参数错误，零副作用 | 修改后重新申请 |
| 2 本地校验 | 无同名 user；`local_port` 本机未被占用；已提供的 `daemon_port` 在同一 daemon 目标主机上未冲突；生成 reservation 候选（仅内存） | 返回冲突原因 | 改参数后重试 |
| 3 探测 | 逐 role 探测矩阵全过（见 §4）；`expected_*` 固化；`role.*.root` 回写绝对路径 | ERROR（spectre role 整体仅 WARNING） | 修复环境后重试 |
| 4 部署 | bridge 文件落到 `role.daemon.root`；产出 `setup_path`（daemon 侧绝对路径，供用户复制到 CIW） | ERROR | 覆盖式重试 |
| 4→5 之间 | 用户自己 `load(setup_path)` 并拉起 daemon；bridge 不参与、不判断是否拉得起来 | 不属于 bridge 一步 | 用户自行重试 |
| 5 连通性 | 能观察到 daemon 可达 + token 比对通过 + 双冒烟通过；**通过后只报告结果、不落盘** | ERROR | 可重试第五步 |
| 6 写注册表 | 用户**显式确认**后 final re-check 并原子落盘（第五步通过不自动保存） | ERROR | 前五步可重跑 |

### 3.2 第五步失败语义

| 现象 | 级别 | 处置 |
|---|---|---|
| daemon 端口不可达 | **ERROR** | 提示在 CIW `load(setup_path)`，不得落盘 |
| token NAK / 不匹配 | **ERROR** | SKILL 零接触；确认 load 的是本 user 的 setup |
| host-key 指纹不匹配 | **ERROR** | 唯一阻断的期望类校验 |
| banner hostname / daemon user 与 `expected_*` 不一致 | WARNING | 记入 report.warnings，不阻断 |
| 命令冒烟失败 / Skill 冒烟 `1+1`≠`2` | **ERROR** | 对应通道未打通 |

### 3.3 deadline 与失败清理

- 各步**各有一条独立的步级 deadline**（默认 30s），步内相位共享、不重置；`runtime.connect_timeout` 是其中的子预算；探测逐项顺序执行；第四步之后用户 `load` 的等待**不计时**；
- 缺省端口的分配、复核与冲突重分配见[中层配置文档 §6.4](../中层/add-中层配置文档.md)；
- 失败/`cancel`/会话断开 → 候选释放见[中层配置文档 §6.4](../中层/add-中层配置文档.md)；不写 registry（本地零残留）；第四步已部署的远端文件不清理，重试为**覆盖式**（`ramic/`、`setup/`、`status/` 重新投送）；
- 第五步通过只报告连通性 OK，**不自动写盘**；第六步由用户显式确认触发（唯一写盘点）；
- 注册结束只允许残留 registry 与远端部署文件。

## 4. 探测矩阵与部署根（唯一 owner）

### 4.1 第三步探测矩阵

| role | 命令可用性（必测） | 专项探测 | 失败级别 |
|---|---|---|---|
| `gui` | ✅ 一次性命令 | SSH 可达 + host-key；`role.gui.root` 可写 | ERROR |
| `daemon` | ✅ 一次性命令 | SSH 可达 + host-key；`role.daemon.python`；`daemon_port` 空闲；`role.daemon.root` 可写 | ERROR |
| `command` | ✅ 一次性命令（命令冒烟） | SSH 可达 + host-key；`role.command.root` 可写 | ERROR |
| `file` | ✅ 一次性命令 | SSH 可达 + host-key；`role.file.root` 可见、可写 | ERROR |
| `spectre` | ✅ 一次性命令 | SSH 可达 + host-key；`role.spectre.root` 可写；`bin` 校验/探测 | **WARNING（不阻断）** |

- `mode=remote` 的 role 执行 SSH 可达 + host-key 检查；`mode=local` 的 role 不做 SSH/host-key/endpoint 检查，改为本机等价检查（命令可用性、端口空闲、root 可写仍按本表执行）；
- `spectre` 探测失败只 WARNING、不阻断；失败字段的提交态见[中层配置文档 §6.2](../中层/add-中层配置文档.md)；
- 其余四个 role 任一必检失败 → 该步失败，不落盘。

### 4.2 根算法与部署

- `root.default` 未提供时 = `~/.virtuoso-bridge/<userid>`，在该 role 工作机器上解释（remote=SSH 账号 HOME，local=运行中层的账号 HOME）；
- `role.<name>.root` 未显式配置 = `<root.default>/<role>`；显式配置即最终根；
- 探测后把展开后的**绝对路径写回各 `role.root`**，运行期不再解析 `~`；
- bridge 文件只部署到 `role.daemon.root`（`ramic/`、`setup/`、`status/`）；相对路径按目标 role 根解析；bridge 不检查该根是否对 gui 可见。

## 5. 注册表生命周期与运维

| 操作 | 语义 |
|---|---|
| 导入 | 启动一次读入内存快照；运行期不读文件 |
| `user update` | 路径以 user 定位、携带 token 校验通过后，白名单字段（`ssh.*`、`root.default`、`role.*`、`runtime.*`、`cdslog.*`、`expected_*`）→ 整体校验 → 原子覆盖；更新 `root.default` 不影响已提交 `role.root`；成功后关闭该 token 缓存连接 |
| `user remove` | 路径以 user 定位、携带 token 校验通过后，原子移除条目并关缓存；**本机解绑 ≠ 远端吊销**（远端 daemon 仍接受原 token，直到 `RBStop()` + 删部署） |
| 机器重装 | 带外确认后显式 update `expected_fingerprint`；未确认前按不匹配拒绝 |
| 跨进程写 | registry 写采用 OS 文件锁 + 读改写原子替换，不丢更新 |
| 端口/租约 | reservation 候选（内存、作用域、冲突重分配）见[中层配置文档 §6.4](../中层/add-中层配置文档.md) |
