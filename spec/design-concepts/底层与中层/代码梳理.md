## 1. 当前执行机制

### 1.1 Skill 链路

```text
上层
 └─ VirtuosoClient.execute_skill(skill_code, timeout)
      └─ TCP 连 localhost:port（本地 daemon 或 SSH 隧道）
         请求 {"skill": ..., "timeout": ...}，SHUT_WR，读到 EOF
              └─ daemon（ipcBeginProcess 在 CIW 中拉起）
                   单行：let(((__vb_r <skill>)) hiFlush() __vb_r)\n
                   多行：临时 .il + load("...il") hiFlush() _vb_eval_result\n
                   watchdog 超时 → SIGINT
                   读 il 回包 STX/NAK + payload + RS，原样回 TCP
                       └─ ramic_bridge.il（CIW 内）
                            evalstring(strcat("(progn " data ")"))
                            成功：02 + %L result + 1e
                            失败：15 + errset.errset + 1e
      中层 _parse_response：02→SUCCESS，15→ERROR → VirtuosoResult
```

关键事实：

- 一条 TCP 连接 = 一个请求 + 一个响应，EOF 分帧；
- daemon 单线程 accept，一个 CIW 同时只跑一条 SKILL；
- `printf` 不回 RPC；返回值与 CIW 输出分离；
- daemon 不执行 shell、不传文件。

### 1.2 命令 / 文件链路（中层 SSH）

```text
SSHClient（解析 GUI/Deploy/Daemon/Spectre/Jump 角色）
  ├─ run_command：persistent shell（base64 分 stdout/stderr/rc）
  │               失败回退 ControlMaster / 一次性 ssh sh -l，重试 transient/CM 错误
  ├─ upload/download：tar/scp 计划 + staging + 原子安装；目录走 tar 管道
  ├─ ensure_remote_setup：检测远端 python → 上传 daemon/il → 生成 setup il（setShellEnvVar）
  └─ ensure_tunnel：ssh -L 端口转发；state.json 记录端口/tunnel PID
```

local 模式：`daemon_host=localhost` 时不建 SSH，loopback 直连 daemon，文件用本地 copy。

### 1.3 配置 / 状态

- `env.py`：`.env` 查找与加载（`VB_*`）；
- `profile.py`：profile 解析、venv 绑定；
- `remote_roles.py`：从 `VB_*_HOST` 解析角色；
- `tunnel.py::save_state/read_state`：`state.json` 每 profile 一份；
- `daemon_guard.py`：连上后查 daemon user/host 事后校验。

## 3. 按五项修改的处置汇总

| 修改项 | 保留 | 删除 | 改造 |
|---|---|---|---|
| 并行 | SSHRunner 全量传输能力 | — | run_command 加 parallel；新 exec channel + 线程池/channel 记账 |
| token | daemon/il 现有 frame 与生命周期 | daemon_guard 强制校验 | 三接口加 token；registry 路由；daemon 校验；il 常量注入 |
| 注册表 | transfer、ssh | env/profile 主路径 | registry/register/connect 新建；SSHClient/bridge 从 registry 取 route；runtime_paths 收拢为工作目录 |
| 远端去 env | daemon 启动/部署机制 | `setShellEnvVar("RB_*")` + il `getShellEnvVar` | setup il 写常量；Spectre 命令显式传环境 |
| CDSlog 增量 | il eval/frame、daemon watchdog | — | il 加 marker/fileLength；daemon 读文件过滤限长；middle 挂 `log` 字段 |

## 4. 结论

- **底层**：文件少但都是关键路径，**整体保留**，只做 token、去 env、CDSlog 三处改造；
- **中层**：`SSHRunner`/`transfer`/`paramiko` 是成熟资产，**整体保留**；改动集中在 `VirtuosoClient` 拆成三端口、`SSHClient` 改 registry 路由、新增 registry/执行器模块；
- **立即要删**：`bridge.py` 里 `run_shell_command` 和混入的 cellview/window/screenshot 等上层业务方法（当前还 import 了已删除的上层模块，导致包无法完整导入）；
- **直接删除**：`env.py`/`profile.py`/`from_env` 与迁移适配器均不保留。
