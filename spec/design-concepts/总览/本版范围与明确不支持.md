# 本版范围与明确不支持

> 版本：v7
> 日期：2026-09-14
> Supersedes：v6（split-host 可观察合同统一为“不保证”）
> 状态：Normative（“本版不做什么”的唯一口径）
> 说明：本文是正式范围文档；README 中的清单只索引本文。每一项都写明“遇到时的行为”，实现必须按此处理，不得静默降级。

## 1. 本版支持的范围（一句话）

四层架构：上层只通过中层**五接口**（Skill 执行 / 命令执行 / 文件执行 / GUI 命令执行 / Spectre 命令执行）工作；中层负责 local/SSH/多用户路由与投送；底层 daemon 只执行 Skill。多用户、并发、CDS.log 增量返回在本版范围内。以下明确不做。

## 2. 明确不支持清单

| # | 不支持项 | 遇到时的行为 | 后续归属 |
|---|---|---|---|
| 1 | Spectre 的高层业务封装（仿真流程、结果解析） | 本版只提供 **Spectre 命令执行**接口（一次性命令）与 `role.spectre.bin` 记录，供上层未来自行封装仿真流程；不提供 `purpose` 参数、不做仿真编排。探测/校验失败只 warning、不阻断注册 | 上层后续 |
| 2 | GUI 图形化业务封装 / deploy 独立 role | 本版只提供 **GUI 命令执行**接口（一次性命令，供窗口枚举/dismiss/bootstrap 类操作）；不提供图形化业务编排。部署只投送到 daemon role 的文件根（`role.daemon.root`），不设置独立 deploy role | 上层后续 |
| 3 | 无 token 旧客户端 / 旧 il | 不支持；请求缺失、null 或不匹配 token → NAK `invalid token`，SKILL 零接触 | 已废弃 |
| 4 | `profile` / `VB_*` / `.env` 及迁移适配 | 已删除，无兼容入口；新用户只走六步注册 | 已废弃 |
| 5 | 非对称签名 / HMAC | 本版 token 是对称授权票；不做双方公私钥 | 后续评估 |
| 6 | `request_id` | 不引入请求字段；daemon 同一时刻只有一个 in-flight，增量按 offset 定界 | 后续按需 |
| 7 | argv / 无 shell 模式、异步 command handle | `RunCommand` 为同步 shell 字符串；长任务由上层 marker/轮询实现 | 后续版本 |
| 8 | split-host 的 CDS.log（CIW 与 daemon 不同主机） | 本版**不保证** split-host：daemon 能读到 IL 回传的 path 就按普通路径返回增量；读不到 → `log=""` + 固定 warning `CDS.log unavailable: <reason>`；`log_level=off` 时无 warning（源头不读）；bridge 不做 split-host 判定。后续方向见[日志返回设计标准 §2](../底层/6-日志返回设计标准.md) | 后续版本 |
| 9 | 全量日志 parser / push stream / 日志数据库 | 只做同步增量返回；全文通过 File 接口自行读取 | 后续版本 |
| 10 | 文件空间安全沙箱 | `role.<name>.root` 只是各 role 的默认工作目录约定，不拦截 `..`/任意绝对路径；隔离依赖 OS 账号权限 | 非目标 |
| 11 | 跨机启动 daemon 的协议（mpsserver / 远程 launcher 等） | 本版不实现。**当前版本 daemon 是 CIW 的本地 `ipcBeginProcess` 子进程**；启动方式与运行账号由站点拓扑决定，bridge 只忠实投送与连接、不参与也不校验 | 后续版本（daemon 可能支持在其他节点启动） |
