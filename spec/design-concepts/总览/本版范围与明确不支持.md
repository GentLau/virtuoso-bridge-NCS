# 本版范围与明确不支持

> 版本：v1
> 日期：2026-09-11
> 状态：Normative（“本版不做什么”的唯一口径）
> 说明：本文是正式范围文档；README 中的清单只索引本文。每一项都写明“遇到时的行为”，实现必须按此处理，不得静默降级。

## 1. 本版支持的范围（一句话）

三层架构：上层只通过中层三接口（Skill / RunCommand / File）工作；中层负责 local/SSH/多用户路由与投送；底层 daemon 只执行 Skill。多用户、并发、CDS.log 增量返回在本版范围内。以下明确不做。

## 2. 明确不支持清单

| # | 不支持项 | 遇到时的行为 | 后续归属 |
|---|---|---|---|
| 1 | `purpose` 参数与 Spectre 业务消费入口 | 不提供 `purpose` 参数；`route.spectre.host/bin` 仅在注册期探测/记录，**探测/校验失败只 warning、不阻断注册**，业务调用不路由到它 | 后续版本 |
| 2 | GUI/deploy 独立 role（`gui_host` / `deploy_host`） | 不提供该字段；daemon 与 GUI 同机，deploy 目标即 daemon 主机 | 后续版本 |
| 3 | 无 token 旧客户端 / 旧 il | 不支持；请求缺失、null 或不匹配 token → NAK `invalid token`，SKILL 零接触 | 已废弃 |
| 4 | `profile` / `VB_*` / `.env` 及迁移适配 | 已删除，无兼容入口；新用户只走六步注册 | 已废弃 |
| 5 | 非对称签名 / HMAC | 本版 token 是对称授权票；不做双方公私钥 | 后续评估 |
| 6 | `request_id` | 不引入请求字段；daemon 同一时刻只有一个 in-flight，增量按 offset 定界 | 后续按需 |
| 7 | argv / 无 shell 模式、异步 command handle | `RunCommand` 为同步 shell 字符串；长任务由上层 marker/轮询实现 | 后续版本 |
| 8 | split-host 的 CDS.log | 日志增量仅支持 daemon 与 CDS.log 同主机；不同主机时本版不返回该增量 | 后续版本 |
| 9 | 全量日志 parser / push stream / 日志数据库 | 只做同步增量返回；全文通过 File 接口自行读取 | 后续版本 |
| 10 | 文件空间安全沙箱 | `deploy.scratch_root` 只是唯一工作目录约定，不拦截 `..`/任意绝对路径；隔离依赖 OS 账号权限 | 非目标 |
