## 1. 设计原则：配置跟随用户

- 每个 user 一份独立配置，只存在于该用户自己的 `registry.json` 和远端自己的部署目录；
- **不预设变量值**：所有值都由注册探测、端口分配、部署流程按需生成，满足需求即可；
- 单个 user 的配置分三部分：**通用**（既非本地也非远端）、**本地**（调用机主要用）、**远端**（业务服务器/Virtuoso 主机主要用）；
- 分类看“**谁主要用它**”，不是看存在哪里：远端参数不是本地没有，只是归到远端这一类；
- 分层：上层只传 token；中层持注册表与运行时策略；底层用 il 常量 / daemon 参数；
- 本地工作目录：启动时可显式传入；**不传则默认现代码的配置目录**（Linux `~/.config/virtuoso_bridge`、Windows `%APPDATA%\virtuoso_bridge`、macOS `~/Library/Application Support/virtuoso_bridge`）；它不是配置项，目录下固定子结构自动创建。
- **每次调用的参数**（`token`、`timeout`、`parallel`）由接口签名决定，**不进配置**。

> 默认值约定：标“默认 X”的参数**可省略**；标“必填”的参数**必须写入**（通常由注册/部署自动生成，用户不需要手写）。

## 2. 单个 user 的配置

### 2.1 通用配置（不属于本地/远端）

| 变量 | 作用（满足什么需求） | 默认值 |
|---|---|---|
| `token` | 每次调用携带的寻址与授权参数；每用户唯一，注册时生成，终生不变；不是绑定会话对象 | 必填（注册时生成） |
| `mode` | `local` / `remote`，决定中层用本地进程还是 SSH 投送 | 必填（注册时确定） |

### 2.2 本地配置（调用机主要用）

| 变量 | 作用（满足什么需求） | 默认值 |
|---|---|---|
| `route.skill.local_port` | 本地隧道端口（remote）或直连端口（local），连接底层 daemon | 默认 `= daemon_port`（remote 模式自动选本地空闲端口） |
| `route.jump` | 可选：跳板机，仅中层路由使用 | 可选，无默认 |
| `expected.ssh_host_key_fingerprint` | 注册时固化主机指纹，连接时比对，防机器漂移/中间人 | 必填（注册探测） |
| `expected.daemon_endpoint_hostname` | 校验隧道实际连接的 daemon 主机名 | 必填（注册探测） |
| `expected.daemon_user` | 期望的远端账号，连接时核对 | 必填 |
| `expected.remote_python` | 注册时确定的远端 python 解释器，部署/启动 daemon 使用 | 默认 `python`（探测失败时） |
| `ssh.backend` | SSH 传输后端（openssh / paramiko） | 默认 `openssh` |
| `ssh.max_sessions` | 并发会话上限，与远端 sshd `MaxSessions` 对齐 | 默认 `10` |
| `ssh.proxy` | 可选：第一跳经 SOCKS5 代理 | 可选，无默认 |
| `ssh.control_master` | 连接复用策略（auto / force / disable），按平台能力选择 | 默认 `auto` |
| `ssh.tool_override` | 可选：ssh/scp/tar 等工具路径覆盖（本地环境需要时） | 可选，无默认 |
| `runtime.thread_pool_size` | 每 token 同时在途请求上限；超限返回错误 | 默认 `32` |
| `runtime.channel_budget` | 每 token 的 SSH channel 预算；超限拒绝 | 默认 `10` |
| `runtime.connect_timeout` | SSH 连接建立超时（传输层一次性配置，不是每调用参数） | 默认 `15`（秒） |
| `cdslog.log_level` | 本次调用返回日志的级别：`off` / `all` / `warn` / `error` | 默认 `all` |
| `cdslog.log_max_bytes` | 单次日志内联长度上限；超限自动降级 error | 默认 `65536` |
**本地工作目录（默认现代码配置目录，可显式传入；不属于配置表）：**

```text
<工作目录>/
  registry.json   ← 注册表
  temp/           ← 本地暂存/缓存
  log/            ← 本地日志
  artifact/       ← 产物输出（截图、导出）
```

- 所有本地文件操作收拢到这个目录；子结构固定，自动创建；不传时用上面默认值；
- 不提供单独的 log/temp 路径配置。

### 2.3 远端配置（业务服务器 / Virtuoso 主机主要用）

| 变量 | 作用（满足什么需求） | 默认值 |
|---|---|---|
| `route.skill.daemon_host` | 底层 daemon 实际监听的主机 | local 默认 `127.0.0.1`；remote 必填 |
| `route.skill.daemon_port` | 远端 daemon 监听端口；每用户分配，保证不冲突 | 必填（注册时分配） |
| `route.command.host` | `RunCommand` 实际执行的主机 | 默认 `= daemon_host` |
| `route.command.user` | 命令执行使用的远端账号 | 默认 `= expected.daemon_user` |
| `route.file.host` | 文件传输目标主机 | 默认 `= command.host` |
| `route.file.root` | 文件传输的根目录/隔离域 | 默认 `= <scratch_root>/id_token` |
| `route.spectre.host` | 可选：独立 Spectre 执行主机 | 默认 `= command.host` |
| `route.spectre.bin` | 可选：注册时探测固化的 spectre 绝对路径，避免依赖远端 shell PATH | 可选，无默认 |
| `deploy.scratch_root` | bridge 远端工作根；每个用户在其下用 token 命名的 `id_token` 子目录区分 | 默认 `~/.virtuoso-bridge` |
远端文件结构（写死，不配置；`id_token` = 该用户 token 命名的目录）：

```text
<scratch_root = ~/.virtuoso-bridge>/id_token/
  ramic/
    ramic_bridge_daemon_3.py   ← daemon（按 python 版本选 3 / 27）
    ramic_bridge_daemon_27.py
    ramic_bridge.il
  setup/
    virtuoso_setup.il         ← 固定名，打印给用户 load
  status/
    daemon_identity.txt       ← 固定名，状态/诊断
```

| 变量 | 作用（满足什么需求） | 默认值 |
|---|---|---|
| `RBDPath`（il 常量） | daemon 脚本实际路径：`<scratch_root>/id_token/ramic/ramic_bridge_daemon_*.py` | 必填（部署生成） |
| `RBPython`（il 常量） | 拉起 daemon 的 python 解释器 | 默认 `python`（探测失败时） |
| `RBPort`（il 常量） | daemon 监听端口 | 必填（= `route.skill.daemon_port`） |
| `RBIdentityPath`（il 常量） | identity 文件路径：`<scratch_root>/id_token/status/daemon_identity.txt` | 必填（部署生成） |
| daemon `token`（argv / il 常量） | daemon 持有用于校验来访请求；不匹配则 SKILL 零接触 | 必填（部署注入） |
| daemon `bind`（argv） | 监听地址（默认回环，仅诊断需要时改） | 默认 `127.0.0.1` |
| `RBLocal`（il 常量） | 调试开关：仅本地监听 | 默认 `nil` |
| `RBEcho`（il 常量） | 调试开关：回显 bridge 消息 | 默认 `nil` |
| `RBDLog`（il 常量） | 调试开关：daemon 日志 | 默认 `nil` |
| Spectre 环境 | 注册时固化 `spectre.bin` 或 cshrc 路径，执行时由中层显式传入 | 可选，无默认 |

## 3. 每用户隔离清单

| 资源 | 隔离方式 |
|---|---|
| token | 每用户唯一，注册表保存 |
| 端口 | 每用户注册表分配 |
| SSH 连接 / channel | 每 token 独立 |
| 部署目录 | `~/.virtuoso-bridge/id_token/`，id_token = 该用户 token 命名的目录 |
| identity 文件 | 每用户一份 |
| 线程池 / channel 预算 | 每 token 独立 |
| CDS.log cursor | daemon 内存（每 CIW 独立） |
| 本地 registry 条目 | 每用户一条 |

## 4. 旧变量迁移映射

### 4.1 本地 `VB_*` → 注册表

| 旧变量 | 新位置 | 处置 |
|---|---|---|
| `VB_REMOTE_HOST` | `route.skill.daemon_host` 缺省 | 迁移 |
| `VB_REMOTE_USER` | `expected.daemon_user` / `route.command.user` | 迁移 |
| `VB_REMOTE_PORT` | `route.skill.daemon_port` | 迁移，改为注册表分配 |
| `VB_LOCAL_PORT` | `route.skill.local_port` | 迁移 |
| `VB_GUI_HOST` / `VB_DEPLOY_HOST` / `VB_DAEMON_HOST` / `VB_SPECTRE_HOST` | 对应 route 字段 | 迁移 |
| `VB_JUMP_HOST` / `VB_JUMP_USER` | `route.jump` / `expected.jump_user` | 迁移 |
| `VB_REMOTE_SCRATCH_ROOT` | `deploy.scratch_root` | 迁移 |
| `VB_CLIENT_ID` / `VB_CLIENT_ID_<profile>` | — | 删除：远端目录按 token 子目录区分，不再做客户端分段 |
| `VB_CADENCE_CSHRC` / `VB_SPECTRE_BIN` | Spectre 环境（显式传入，不预设远端 shell） | 迁移 |
| `VB_SSH_BACKEND` / `VB_SSH_MAX_SESSIONS` / `VB_SSH_PROXY` | `ssh.*` | 迁移 |
| `VB_FORCE_CONTROL_MASTER` / `VB_DISABLE_CONTROL_MASTER` | `ssh.control_master` | 迁移 |
| `VB_SSH_CMD` / `VB_SCP_CMD` / `VB_TAR_CMD` / `VB_SSH_CONFIG` | `ssh.tool_override` | 迁移或保留本地 |
| `VB_ALLOW_CROSS_USER_DAEMON` | — | 删除（token 取代） |
| `VB_PROFILE` / `VB_*_<profile>` | `user` | 删除主路径 |

### 4.2 远端 `RB_*` → il 常量 / daemon 参数

| 旧变量 | 新位置 | 处置 |
|---|---|---|
| `RB_DAEMON_PATH` | `RBDPath` il 常量 | 改造 |
| `RB_PYTHON_PATH` | `RBPython` il 常量 | 改造 |
| `RB_PORT` | `RBPort` il 常量 | 改造 |
| `RB_IDENTITY_PATH` | `RBIdentityPath` il 常量 | 改造 |
| daemon argv `[host, port]` | daemon argv `[host, port, token]` | 改造 |

## 5. 迁移顺序

```text
1. registry.json 数据模型 + 冷启动读取
2. user register 注册探测 → 端口分配 → 落盘
3. 部署流程写 il 常量 + token，去掉 setShellEnvVar
4. runtime / ssh / cdslog 策略接入 registry
5. from_env / profile 降级为迁移适配器，最终删除
```
