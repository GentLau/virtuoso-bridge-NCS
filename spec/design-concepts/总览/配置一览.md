# 配置一览

> 版本：Draft v6
> 日期：2026-09-11
> 状态：已冻结（配置与注册输入的唯一规范源）
> Supersedes：Draft v5 及已删除的《注册配置一览》；注册“可提交哪些参数”由本文 §4 统一回答。

## 1. 设计原则：配置跟随用户

- 本地只有一份 `registry.json`，`user` 为键，每个 user 一条独立条目；配置的另一半在该用户远端的部署目录。
- 不预设变量值：值由注册探测、端口分配、部署流程按需生成，满足需求即可。
- 单个 user 的配置分三部分：通用、本地（调用机主要用）、远端（业务服务器/Virtuoso 主机主要用）；分类看“谁主要用它”。
- 分层：上层只传 token；中层持注册表与运行时策略；底层用 il 常量 / daemon 参数。
- 本地工作目录：启动时可显式传入；不传则用平台配置目录（Linux `~/.config/virtuoso_bridge`、Windows `%APPDATA%\virtuoso_bridge`、macOS `~/Library/Application Support/virtuoso_bridge`）。它不是配置项，子结构固定自动创建。
- 每次调用的参数（`token`、`timeout`、`parallel`、`recursive`、`log_level`、`log_max_bytes`）由接口签名决定，不进配置。

> 默认值约定：标“默认 X”可省略；标“必填”必须写入（通常由注册/部署自动生成）。

## 2. 单个 user 的配置

### 2.1 通用配置（不属于本地/远端）

| 变量 | 作用 | 默认值 |
|---|---|---|
| `token` | 每次调用携带的寻址与授权参数；每用户唯一，注册时生成，终生不变 | 必填（注册时生成） |
| `mode` | `local` / `remote`，决定中层用本地进程还是 SSH 投送；**申请方显式提供，不推断** | 必填 |

### 2.2 本地配置（调用机主要用）

| 变量 | 作用 | 默认值 |
|---|---|---|
| `route.skill.local_port` | 本地隧道端口（remote）或直连端口（local） | remote 默认自动选本地空闲端口；local 必须 `= daemon_port` |
| `route.jump.host/user` | 可选跳板机，仅中层路由使用 | 可选，无默认 |
| `expected.ssh_endpoints` | **每个 SSH endpoint(host/user/jump) 的 host-key 指纹 map**：第三步探测获得并记录，第五步/运行期逐 endpoint 比对（来源优先级见 §5） | 必填（注册探测；local 模式为空） |
| `expected.daemon_endpoint_hostname` | 校验隧道实际连接的 daemon 主机名 | 必填（注册探测） |
| `expected.daemon_user` | 期望远端账号，连接时核对 | 必填 |
| `expected.remote_python` | 第三步探测确定的远端 python，部署/启动 daemon 用；探测失败=注册失败 | 必填 |
| `ssh.backend` | SSH 后端 openssh / paramiko | 默认 `openssh` |
| `ssh.max_sessions` | 每 endpoint 并发会话上限，与远端 sshd `MaxSessions` 对齐 | 默认 `10` |
| `ssh.proxy` | 可选 SOCKS5 第一跳 | 可选 |
| `ssh.control_master` | 复用策略 auto/force/disable；复用边界始终 per-token×endpoint（ControlPath 含 token 的不可逆 hash） | 默认 `auto` |
| `ssh.tool_override` | 可选 ssh/scp/tar 工具路径覆盖 | 可选 |
| `runtime.thread_pool_size` | 每 token 同时在途请求上限；超限返回错误 | 默认 `32` |
| `runtime.channel_budget` | 每 token 每 endpoint 的 SSH channel 预算；超限拒绝 | 默认 `10` |
| `runtime.connect_timeout` | 连接建立超时（一次性配置） | 默认 `15` 秒 |
| `cdslog.log_level` | 返回日志级别 `off/all/warn/error`；`off` 从 IL 源头不 flush/不读文件/不注入输出 | 默认 `all` |
| `cdslog.log_max_bytes` | 单次日志内联长度上限；超限自动降级 error | 默认 `65536` |

本地工作目录（非配置项）：

```text
<工作目录>/
  registry.json   ← 注册表（权限 0600）
  temp/ log/ artifact/
```

### 2.3 远端配置（业务服务器 / Virtuoso 主机主要用）

| 变量 | 作用 | 默认值 |
|---|---|---|
| `route.skill.daemon_host` | daemon 监听主机 | local `127.0.0.1`；remote 必填 |
| `route.skill.daemon_port` | daemon 监听端口，每用户分配不冲突 | 必填（注册分配） |
| `route.command.host` | RunCommand 执行主机 | 默认 `= daemon_host` |
| `route.command.user` | 命令执行账号 | 默认 `= expected.daemon_user` |
| `route.file.host` | 文件传输目标主机 | 默认 `= command.host` |
| `route.file.root` | 默认可用工作目录（不是沙箱，见三层架构 §5.6） | 默认 `<scratch_root>/<user>`（**路径用用户名，不用 token**） |
| `route.spectre.host` | 可选：未来 Spectre 执行主机（本版不消费） | 默认 `= command.host` |
| `route.spectre.bin` | 可选：显式提供则在该 host 校验可用性，不可用报告用户；未提供则第三步自动探测（探测到即已通过可用性验证；探测失败仅 warning，不阻断注册） | 可选 |
| `deploy.scratch_root` | 远端 bridge 工作根，每用户按唯一用户名分子目录 | 默认 `~/.virtuoso-bridge`（local 模式=本地工作目录） |

远端固定目录（写死，不配置；目录名=用户名）：

```text
<scratch_root>/<user>/
  ramic/   ramic_bridge_daemon_3.py · ramic_bridge_daemon_27.py · ramic_bridge.il
  setup/   virtuoso_setup.il
  status/  daemon_identity.txt
```

il/daemon 常量（部署生成，不配置）：`RBDPath`、`RBPython`、`RBPort`、`RBIdentityPath`、daemon `token`；daemon `bind` 固定 `127.0.0.1`；`RBLocal/RBEcho/RBDLog` 调试开关默认 `nil`。

## 3. 每用户隔离清单

| 资源 | 隔离方式 |
|---|---|
| token | 每用户唯一 |
| 端口 | 每用户注册表分配 |
| SSH 连接/channel | 每 token×endpoint 独立，禁止跨 token 复用 |
| 部署目录 | `~/.virtuoso-bridge/<user>/` |
| identity 文件 | 每用户一份 |
| 线程池/channel 预算 | 每 token 独立 |
| CDS.log 读取 | daemon 本地读，每请求 offset 定界 |
| 文件空间 | 仅默认目录约定 + OS 账号权限，**非安全沙箱** |

## 4. 注册可提交参数目录（唯一来源）

### 4.1 可提交参数

| 参数 | 远程 | 本地 | 性质 |
|---|---|---|---|
| `mode` | 必填 | 必填 | `local` / `remote`，申请方显式提供，不推断 |
| `user`（`^[A-Za-z0-9][A-Za-z0-9._-]{0,63}$`） | 必填 | 必填 | 人类可读 id + 路径名，非安全凭证 |
| SSH host | 必填 | 不需要 | command/file 通道主机（v1=deploy 主机） |
| SSH user | 必填 | 不需要 | SSH 登录账号 |
| daemon host | 可选（缺省=SSH host） | 不需要（隐含 127.0.0.1） | Skill 通道主机；与 GUI 同机 |
| daemon user | 可选（缺省=SSH user） | 不需要 | daemon 进程 Unix 用户 |
| daemon port | 可选 | 可选 | 缺省注册探测分配 |
| local port | 可选 | 不适用 | remote 隧道本地端口，缺省自动分配 |
| token | 可选 | 可选 | 缺省自动生成 `^[A-Za-z0-9._-]{1,64}$` |
| scratch root | 可选 | 可选 | 部署根 |
| jump host/user | 可选 | 不需要 | 跳板机 |
| ssh.* / runtime.* / cdslog.* | 可选 | 可选 | 缺省见 §2 默认值 |
| `route.file.host/root`、`route.spectre.host/bin` | 可选 | 可选 | 缺省见 §2；spectre.bin 未提供时自动探测 |

### 4.2 探测与校验结果如何进入注册表

第三步的结果分三类，**不笼统叫“固化”**：

1. **探测得到的比对基准**：`expected.ssh_endpoints`、`expected.daemon_endpoint_hostname`、`expected.daemon_user`、`expected.remote_python`——由探测获得，写入 `expected` 供第五步与运行期比对；其中 `daemon_user` 若用户显式提供，则只校验存在性。
2. **校验结论（不是参数）**：daemon 端口占用、部署根可见性——占用/不可见即该参数校验不通过，报告用户或重新分配，不写入注册表。
3. **显式提供→校验，未提供→自动探测**：`route.spectre.bin`——用户显式提供则校验可用性，失败报告用户；未提供则自动探测，**探测到的路径一定可用**，探测失败仅 warning、不阻断注册。

## 5. 输入安全与首信任（冻结）

- `user`：字符集见 §4.1；禁止 `/`、`\`、`..`、绝对路径；部署前 containment 校验，越界即注册失败。
- `token`：字符集见 §4.1；存 registry（0600）与 il/daemon；ControlPath 只用其不可逆 hash；轮换=删除用户重新注册。
- host-key 首信任优先级（不再依赖“首连即 TOFU”）：
  1. known_hosts 已存在且匹配 → 记录该指纹作为比对基准；
  2. 用户显式提供指纹 → 校验后记录；
  3. 两者皆无 → **注册失败**，提示用户带外确认后添加，再重试。
