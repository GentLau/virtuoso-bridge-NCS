# 配置一览

> 版本：Draft v7
> 日期：2026-09-11
> 状态：已冻结（配置与注册输入的唯一规范源）
> Supersedes：Draft v6；注册“可提交哪些参数”由本文 §4 统一回答。

## 1. 设计原则：配置跟随用户

- 本地只有一份 `registry.json`，`user` 为键，每个 user 一条独立条目；配置的另一半在该用户远端的部署目录。
- 不预设变量值：值由用户提供、注册探测、端口分配、部署流程按需生成，满足需求即可。
- **每个配置项都标注类型**：`配置` / `环境` / `校验`，三类处理规则见 §4.1。
- 单个 user 的配置分三部分：通用、本地、远端；**分类看字段在哪里被消费**——远端执行/运行消费的字段归远端，本地路由/比对消费的字段归本地。
- 分层：上层只传 token；中层持注册表与运行时策略；底层用 il 常量 / daemon 参数。
- 本地工作目录：启动时可显式传入；不传则用平台配置目录；不是配置项，子结构固定自动创建。
- **双层语义**：每次调用携带的字段是 `token`、`timeout`、`parallel`、`recursive`；`cdslog.log_level` / `cdslog.log_max_bytes` 是每用户持久化配置，由中层在发出 daemon 请求时从 registry 填充。

> 默认值约定：标“默认 X”可省略；标“必填”必须写入（通常由注册/部署自动生成）。

## 2. 单个 user 的配置

### 2.1 通用配置（不属于本地/远端）

| 变量 | 作用 | 类型 | 默认值 |
|---|---|---|---|
| `token` | 每次调用携带的寻址与授权参数；每用户唯一，注册时生成，终生不变 | 配置 | 必填（注册时生成） |
| `mode` | `local` / `remote`，决定中层用本地进程还是 SSH 投送；申请方显式提供，不推断 | 配置 | 必填 |

### 2.2 本地配置（调用机主要用）

| 变量 | 作用 | 类型 | 默认值 |
|---|---|---|---|
| `route.skill.local_port` | 本地隧道端口（remote）或直连端口（local） | 配置 | remote 默认自动选本地空闲端口；local 必须 `= daemon_port` |
| `expected.ssh_endpoints` | 每个 SSH endpoint 的 host-key 指纹 map：**远端探测得到、拿回本地比对**；canonical key = `host|user|jump|proxy`，值 = `SHA256:<fingerprint>` | 校验 | 必填（注册探测；local 模式为空） |
| `expected.daemon_endpoint_hostname` | daemon 主机名比对基准（banner 漂移可被发现），**本地比对消费** | 校验 | 必填（注册探测） |
| `expected.daemon_user` | daemon 进程 Unix 用户比对基准，**本地比对消费** | 校验 | 必填（注册探测） |
| `route.jump.host/user` | 可选跳板机，仅中层路由使用 | 配置 | 可选，无默认 |
| `ssh.backend` | SSH 后端 openssh / paramiko | 配置 | 默认 `openssh` |
| `ssh.max_sessions` | 每 endpoint 并发会话上限，与远端 sshd `MaxSessions` 对齐 | 配置 | 默认 `10` |
| `ssh.proxy` | 可选 SOCKS5 第一跳 | 配置 | 可选 |
| `ssh.control_master` | 复用策略 auto/force/disable；复用边界始终 per-token×endpoint（ControlPath 含 token 的不可逆 hash） | 配置 | 默认 `auto` |
| `ssh.tool_override` | 可选 ssh/scp/tar 工具路径覆盖 | 配置 | 可选 |
| `runtime.thread_pool_size` | 每 token 同时在途请求上限；超限返回错误 | 配置 | 默认 `32` |
| `runtime.channel_budget` | 每 token 每 endpoint 的 SSH channel 预算；超限拒绝 | 配置 | 默认 `10` |
| `runtime.connect_timeout` | 连接建立超时（一次性配置） | 配置 | 默认 `15` 秒 |
| `cdslog.log_level` | 返回日志级别 `off/all/warn/error`；`off` 从 IL 源头不 flush/不读文件/不注入输出 | 配置 | 默认 `all` |
| `cdslog.log_max_bytes` | 单次日志内联长度上限；超限自动降级 error | 配置 | 默认 `65536` |

本地工作目录（非配置项）：

```text
<工作目录>/
  registry.json   ← 注册表（权限 0600）
  temp/ log/ artifact/
```

### 2.3 远端配置（业务服务器 / Virtuoso 主机主要用）

| 变量 | 作用 | 类型 | 默认值 |
|---|---|---|---|
| `environment.remote_python` | 远端 python 解释器，**远端部署/启动 daemon 时消费**；探测为 python2 则远端就用 python2 | 环境 | 必填（探测失败=注册失败） |
| `route.skill.daemon_host` | daemon 监听主机 | 配置 | local `127.0.0.1`；remote 必填 |
| `route.skill.daemon_port` | daemon 监听端口，每用户分配不冲突 | 配置 | 必填（注册分配） |
| `route.command.host` | RunCommand 执行主机 | 配置 | 默认 `= daemon_host` |
| `route.command.user` | 命令执行 SSH 登录账号 | 配置 | 默认 `= SSH 登录用户`；`expected.daemon_user` 只用于第五步比对，不参与命令登录 |
| `route.file.host` | 文件传输目标主机 | 配置 | 默认 `= command.host` |
| `route.file.user` | 文件传输 SSH 登录账号 | 配置 | 默认 `= command.user` |
| `route.spectre.host` | Spectre 执行主机，**日后远端执行 spectre 时消费** | 配置 | 默认 `= command.host` |
| `route.spectre.user` | Spectre 执行 SSH 登录账号 | 配置 | 默认 `= command.user` |
| `route.spectre.bin` | **远端执行 spectre 时消费**；显式提供→校验，未提供→自动探测；**校验/探测失败仅 warning、不阻断注册**（本版无消费入口，结果仅记录供未来使用） | 环境 | 可选 |
| `deploy.scratch_root` | **该用户唯一的 bridge 工作目录**（部署文件与文件操作默认根共用这一个目录，不是沙箱，见三层架构 §5.6） | 配置 | 默认 `~/.virtuoso-bridge/<user>`（local 模式=本地工作目录/<user>） |

远端固定目录（写死，不配置；目录名=用户名）：

```text
<deploy.scratch_root>/            ← 唯一工作目录（= 部署根 = 文件默认根）
  ramic/   ramic_bridge_daemon_3.py · ramic_bridge_daemon_27.py · ramic_bridge.il
  setup/   virtuoso_setup.il
  status/  daemon_identity.txt
```

il/daemon 常量（部署生成，不配置）的类型：`RBDPath`=配置、`RBPython`=环境（等于 `environment.remote_python`）、`RBPort`=配置、`RBIdentityPath`=配置、daemon `token`=配置、`bind`=配置（固定 `127.0.0.1`）、`RBLocal/RBEcho/RBDLog`=配置（默认 `nil`）。

## 3. 每用户隔离清单

| 资源 | 隔离方式 |
|---|---|
| token | 每用户唯一 |
| 端口 | 每用户注册表分配 |
| SSH 连接/channel | 每 token×endpoint 独立，禁止跨 token 复用 |
| 部署目录/默认文件根 | `deploy.scratch_root`（默认 `~/.virtuoso-bridge/<user>/`） |
| identity 文件 | 每用户一份 |
| 线程池/channel 预算 | 每 token 独立 |
| CDS.log 读取 | daemon 本地读，每请求 offset 定界 |
| 文件空间 | 仅默认目录约定 + OS 账号权限，非安全沙箱 |

## 4. 注册参数目录（唯一来源）

### 4.1 三种类型的处理规则

| 类型 | 处理规则 |
|---|---|
| **配置** | 由用户提供；只做格式/范围/查重校验，校验失败=拒绝申请；无“自动探测” |
| **环境** | **默认自动探测**；用户显式提供时只做**校验**，不可用则报告用户该参数有问题并拒绝；探测结果供部署/运行使用。**唯一例外 `route.spectre.bin`**：校验/探测失败仅 warning、不阻断注册（本版无消费入口，结果仅记录），规则以 §4.2 为准 |
| **校验** | 探测获得并记录到 `expected`，只用于后续比对、**不参与业务**；运行期不一致 → **WARNING，不阻断**。唯一例外：host-key 指纹属于安全身份校验，不匹配 → **ERROR（阻断）** |

### 4.2 可提交参数

| 参数 | 类型 | 远程 | 本地 | 性质 |
|---|---|---|---|---|
| `mode` | 配置 | 必填 | 必填 | `local` / `remote`，申请方显式提供，不推断 |
| `user`（`^[A-Za-z0-9][A-Za-z0-9._-]{0,63}$`） | 配置 | 必填 | 必填 | 人类可读 id + 路径名，非安全凭证 |
| SSH host | 配置 | 必填 | 不需要 | command/file 通道主机（v1=deploy 主机） |
| SSH user | 配置 | 必填 | 不需要 | SSH 登录账号 |
| daemon host | 配置 | 可选（缺省=SSH host） | 不需要（隐含 127.0.0.1） | Skill 通道主机；与 GUI 同机 |
| daemon user | 配置 | 可选（缺省=SSH user） | 不需要 | daemon 进程 Unix 用户 |
| daemon port | 配置 | 可选 | 可选 | 缺省注册探测分配 |
| local port | 配置 | 可选 | 不适用 | remote 隧道本地端口，缺省自动分配 |
| token | 配置 | 可选 | 可选 | 缺省自动生成 `^[A-Za-z0-9._-]{1,64}$` |
| scratch root | 配置 | 可选 | 可选 | 部署根 |
| jump host/user | 配置 | 可选 | 不需要 | 跳板机 |
| `ssh.*` / `runtime.*` / `cdslog.*` | 配置 | 可选 | 可选 | 缺省见 §2 默认值 |
| `expected.ssh_endpoints`（显式指纹） | 校验 | 可选 | 不适用 | 用户显式提供 per-endpoint 指纹则校验后记录；key/算法同 §2 |
| `route.file.host`、`route.spectre.host` | 配置 | 可选 | 可选 | 缺省见 §2 |
| `route.spectre.bin` | 环境 | 可选 | 可选 | 显式提供→校验；未提供→自动探测；**失败仅 warning、不阻断注册** |

### 4.3 探测、校验、期望如何进入注册表

1. **环境探测结果**：`environment.remote_python` 写入注册表供远端部署/运行使用；`route.spectre.bin` 探测/校验结果仅记录，失败仅 warning；端口空闲与部署根可见性只是校验结论，不写注册表。
2. **校验比对基准**：`expected.ssh_endpoints`、`expected.daemon_endpoint_hostname`、`expected.daemon_user` 由探测获得并记录，供第五步/运行期比对；不一致按 §4.1 的 WARNING（host-key 例外 ERROR）处理，不参与业务。
3. **系统配置**：`user`/`mode`/`ssh.*`/`runtime.*`/`cdslog.*` 等只在第二步做约束校验，不探测、不比对。

## 5. 输入安全与首信任（冻结）

- `user`：字符集见 §4.2；禁止 `/`、`\`、`..`、绝对路径；部署前 containment 校验，越界即注册失败。
- 跨平台路径规则：Windows 下 user 按**大小写不敏感**查重（`Alice` 与 `alice` 视为同一）；禁止保留设备名（`CON/PRN/AUX/NUL/COM1-9/LPT1-9`，含扩展名形式）与结尾 `.`/空格；路径规范化后冲突即拒绝注册。
- `token`：字符集见 §4.2；存 registry（0600）与 il/daemon；ControlPath 只用其不可逆 hash；轮换=删除用户重新注册。
- host-key 首信任优先级（不再依赖“首连即 TOFU”）：
  1. known_hosts 已存在且匹配 → 记录该指纹作为比对基准；
  2. 用户显式提供指纹 → 校验后记录；
  3. 两者皆无 → 注册失败，提示用户带外确认后添加，再重试。


## 6. Canonical 注册 API / Schema 附录（冻结）

### 6.1 注册请求 canonical 字段

| 字段 | 类型 | 必填 | 说明 |
|---|---|---|---|
| `mode` | `local` / `remote` | 是 | 显式提供，不推断 |
| `user` | string | 是 | §5 字符集与跨平台规则 |
| `host` / `ssh_user` | string | remote 必填 | SSH 登录目标 |
| `daemon_host` / `daemon_user` | string | 可选 | 缺省=host/ssh_user |
| `daemon_port` / `local_port` | int | 可选 | 缺省自动分配 |
| `token` | string | 可选 | 缺省自动生成 |
| `scratch_root` | string | 可选 | 部署/文件默认根 |
| `jump_host` / `jump_user` | string | 可选 | 跳板 |
| `ssh.*` / `runtime.*` / `cdslog.*` | — | 可选 | 缺省见 §2 |
| `expected.ssh_endpoints` | map | 可选 | 显式 per-endpoint 指纹，key=`host\|user\|jump\|proxy` |
| `route.spectre.host/bin` | — | 可选 | 见 §2；bin 失败非阻断 |

未知字段：**拒绝注册**（400/参数错误），不静默忽略。

### 6.2 registry 条目 canonical schema

以 `user` 为键，唯一 `token`；字段与 §2 一致，完整 JSON 示例：

```json
{
  "users": {
    "alice": {
      "token": "a3f9c2…",
      "mode": "remote",
      "route": {
        "skill": {"local_port": 65082, "daemon_host": "daemon-a", "daemon_port": 65081},
        "command": {"host": "server-a", "user": "ssh-user"},
        "file": {"host": "server-a", "user": "ssh-user"},
        "spectre": {"host": "server-a", "user": "ssh-user", "bin": "/opt/…/spectre"},
        "jump": {"host": "jump-a", "user": "jump-user"}
      },
      "expected": {
        "ssh_endpoints": {"server-a|ssh-user|jump-a|jump-user|": "SHA256:…"},
        "daemon_endpoint_hostname": "daemon-a",
        "daemon_user": "daemon-user"
      },
      "environment": {"remote_python": "/opt/…/python3"},
      "deploy": {"scratch_root": "~/.virtuoso-bridge/alice"},
      "ssh": {"backend": "openssh", "max_sessions": 10, "proxy": null,
              "control_master": "auto", "tool_override": {}},
      "runtime": {"thread_pool_size": 32, "channel_budget": 10, "connect_timeout": 15.0},
      "cdslog": {"log_level": "all", "log_max_bytes": 65536},
      "registered_at": 1725…
    }
  }
}
```

### 6.3 mode × route 兼容矩阵

| mode | daemon_host | command.host | file.host | spectre.host | SSH |
|---|---|---|---|---|---|
| local | 必须 127.0.0.1 | 必须 127.0.0.1 | 必须 127.0.0.1 | 必须 127.0.0.1 | 无 |
| remote | 任意（默认=host） | 任意（默认=daemon_host） | 任意（默认=command.host） | 任意（默认=command.host） | 有 |

### 6.4 端口 reservation / TOCTOU

1. 第二步对 registry 内端口查重；
2. 第三步对目标机做 bind/占用探测；
3. 第四步部署前再次确认端口空闲，**冲突则自动重新分配并重试一次**，仍冲突即拒绝注册。

### 6.5 endpoint canonical key

`host|user|jump|proxy`（缺省部分为空串）；同 key 共享一条 SSH 连接与 ControlMaster，不同 key 不共享。
