# 配置一览

> 版本：Draft v10
> 日期：2026-09-14
> 状态：已冻结（配置与注册输入的唯一规范源）
> Supersedes：Draft v8；注册可提交参数目录见 §4，canonical 注册 API 见 §6。

## 1. 设计原则：配置跟随用户

- 本地只有一份 `registry.json`，`user` 为键，每个 user 一条独立条目；配置的另一半在该用户远端的部署目录。
- 不预设变量值：值由用户提供、注册探测、端口分配、部署流程按需生成，满足需求即可。
- **每个配置项都标注类型**：`配置` / `环境` / `校验`，三类处理规则见 §4.1。
- 单个 user 的配置分四块：通用（token/mode）、全局 SSH 默认、五个 role、其他每用户配置；**分类看字段在哪里被消费**——远端执行/运行消费的字段归远端，本地路由/比对消费的字段归本地。
- 分层：上层只传 token；中层持注册表与运行时策略；底层用 il 常量 / daemon 参数。
- 本地工作目录：启动时可显式传入；不传则用平台配置目录；不是配置项，子结构固定自动创建。
- **双层语义**：每次调用携带的字段是 `token`、`timeout`、`parallel`、`recursive`（后两者只出现在命令/文件接口）；`cdslog.log_level` / `cdslog.log_max_bytes` 是每用户持久化配置，由中层在发出 daemon 请求时从 registry 填充。接口共 5 个，见[三层整体架构设计 §4.1](三层整体架构设计.md)。

> 默认值约定：标“默认 X”可省略；标“必填”必须写入（通常由注册/部署自动生成）。

## 2. 单个 user 的配置

### 2.1 通用配置

| 变量 | 作用 | 类型 | 默认值 |
|---|---|---|---|
| `token` | 每次调用携带的寻址与授权参数；每用户唯一，注册时生成，终生不变 | 配置 | 必填（注册时生成） |
| `mode` | `local` / `remote`，决定中层用本地进程还是 SSH 投送；申请方显式提供，不推断 | 配置 | 必填 |

### 2.2 全局默认策略（SSH 连接 + 文件根）

五个 role 的每个字段**缺省都回退到这里对应的字段**；role 写了自己就用 role 自己的（field 级 fallback，唯一规则在本节，其余文档只索引）。SSH 连接字段 remote 消费、local 不适用；`root.default` 在两种模式下都参与 role 文件根的默认计算。

| 变量 | 作用 | 类型 | 默认值 |
|---|---|---|---|
| `ssh.default.host` | 各 role 缺省 SSH 登录主机 | 配置 | remote 必填；local 不适用 |
| `ssh.default.user` | 各 role 缺省 SSH 登录账号 | 配置 | remote 必填；local 不适用 |
| `ssh.default.jump_host` | 各 role 缺省跳板主机 | 配置 | 可选 |
| `ssh.default.jump_user` | 各 role 缺省跳板账号 | 配置 | 可选 |
| `ssh.default.proxy` | 各 role 缺省 SOCKS5 第一跳 | 配置 | 可选 |
| `ssh.backend` | SSH 后端 openssh / paramiko | 配置 | 默认 `openssh` |
| `ssh.control_master` | 复用策略 auto/force/disable；复用边界是 token（ControlPath 含 token 不可逆 hash，多 endpoint 再分段），跨 token 不共享 | 配置 | 默认 `auto` |
| `ssh.tool_override` | 可选 ssh/scp/tar 工具路径覆盖 | 配置 | 可选 |
| `root.default` | 各 role 文件根的**全局默认基准**；role 未显式配 `root` 时其根 = `root.default/<role>` | 配置 | **实际默认 `~/.virtuoso-bridge/<userid>`**（local 模式 = `<本地工作目录>/<userid>`） |

### 2.3 五个 role（结构相同；daemon 多两个端口字段）

每个 role 都拥有 `host / user / jump_host / jump_user / proxy / root` 六个字段：连接字段缺省回退 §2.2 的 `ssh.default.*`，`root` 缺省回退 `root.default/<role>`（`root.default` 默认已是 `~/.virtuoso-bridge/<userid>`）。**一个注册账号最多连向五个不同目标。**

| role | 承载的业务 | 该 role 上执行的探测 | 额外字段 |
|---|---|---|---|
| `role.gui` | Virtuoso CIW / X11；被 **GUI 命令执行**（一次性命令）消费 | SSH 可达 + host-key；**命令可用性（一次性命令）**；`role.gui.root` 可写 | 无 |
| `role.daemon` | Skill 通道：daemon 监听主机；bridge 文件部署目标 | SSH 可达 + host-key；**命令可用性**；remote python；daemon_port 空闲；`role.daemon.root` 可写 | `daemon_port`（必填，注册分配）；`local_port`（remote 隧道本地端口，自动分配；local 必须 `= daemon_port`） |
| `role.command` | 通用命令执行主机（常驻 shell + 显式并行） | SSH 可达 + host-key；**命令可用性（命令冒烟）**；`role.command.root` 可写 | 无 |
| `role.file` | 文件传输目标主机（上传/下载） | SSH 可达 + host-key；**命令可用性**；`role.file.root` 可见、可写 | 无 |
| `role.spectre` | Spectre 执行主机；被 **Spectre 命令执行**（一次性命令，上层预留）消费 | SSH 可达 + host-key（失败仅 WARNING）；**命令可用性**；`role.spectre.root` 可写；bin 显式校验/自动探测（失败仅 WARNING） | `bin`（可选记录） |

- local 模式：五个 role 全部固定为 `127.0.0.1` / 本机用户，无 SSH、无 jump/proxy，不读 `ssh.default.*`；
- daemon role 是唯一带端口字段的 role；`environment.remote_python` 只在 daemon role 探测并在 daemon role 消费；
- 逐 role 的职责、探测失败级别与 endpoint 规则由[多节点设计](../底层与中层/多节点设计.md)唯一 owner 定义，本表只列字段与探测项。

### 2.4 其他每用户配置

| 变量 | 作用 | 类型 | 默认值 |
|---|---|---|---|
| `environment.remote_python` | 远端 python 解释器；daemon role 探测、daemon role 部署/启动时消费 | 环境 | 必填（探测失败=注册失败） |
| `expected.ssh_endpoints` | 五个 role 解析后的 endpoint → host-key 指纹 map；key 见 §6.5，值 = `SHA256:<fingerprint>`；spectre endpoint 失败仅 WARNING | 校验 | 必填（注册探测；local 模式为空） |
| `expected.daemon_endpoint_hostname` | daemon 主机名比对基准（banner 漂移可发现），本地比对消费 | 校验 | 必填（注册探测） |
| `expected.daemon_user` | daemon role 的 Unix 账号比对基准（daemon 由该账号运行 Virtuoso/daemon），本地比对消费 | 校验 | 必填（注册探测） |
| `runtime.thread_pool_size` | 每 token 同时在途请求上限；超限返回错误 | 配置 | 默认 `32` |
| `runtime.channel_budget` | **每 token 一份**的 SSH channel 预算，token 内所有 endpoint 共用；超限返回 `channel budget exceeded` | 配置 | 默认 `10` |
| `runtime.connect_timeout` | 连接建立超时（一次性配置） | 配置 | 默认 `15` 秒 |
| `cdslog.log_level` | 返回日志级别 `off/all/warn/error`；`off` 从 IL 源头不 flush/不读文件/不注入输出 | 配置 | 默认 `all` |
| `cdslog.log_max_bytes` | 单次日志内联长度上限；超限自动降级 error | 配置 | 默认 `65536` |

本地工作目录（非配置项）：

```text
<工作目录>/
  registry.json   ← 注册表（权限 0600）
  temp/ log/ artifact/
```

daemon role 根下的固定目录（写死，不配置；目录名=用户名）：

```text
<role.daemon.root>/
  ramic/   ramic_bridge_daemon_3.py · ramic_bridge_daemon_27.py · ramic_bridge.il
  setup/   virtuoso_setup.il
  status/  daemon_identity.txt
```

il/daemon 常量（部署生成，不配置）的类型：`RBDPath`=配置、`RBPython`=环境（等于 `environment.remote_python`）、`RBPort`=配置、`RBIdentityPath`=配置、daemon `token`=配置、`bind`=配置（固定 `127.0.0.1`）、`RBLocal/RBEcho/RBDLog`=配置（默认 `nil`）。

## 3. 每用户隔离清单

| 资源 | 隔离方式 |
|---|---|
| token | 每用户唯一 |
| 端口 | 每用户注册表分配 |
| SSH 连接 | 同一 token 内按 endpoint 去重复用；跨 token 不共用 |
| 各 role 文件根 | `role.<name>.root`（缺省 `root.default/<role>`，`root.default` 默认 `~/.virtuoso-bridge/<userid>`）；role 之间互不共享、无互相可见要求 |
| identity 文件 | 每用户一份 |
| 线程池/channel 预算 | 每 token 独立 |
| CDS.log 读取 | daemon 本地读，每请求 offset 定界 |
| 文件空间 | 仅默认目录约定 + OS 账号权限，非安全沙箱 |

## 4. 注册参数目录（唯一来源）

### 4.1 三种类型的处理规则

| 类型 | 处理规则 |
|---|---|
| **配置** | 由用户提供；只做格式/范围/查重校验，校验失败=拒绝申请；无“自动探测” |
| **环境** | **默认自动探测**；用户显式提供时只做**校验**，不可用则报告用户该参数有问题并拒绝；探测结果供部署/运行使用。**唯一例外 `role.spectre.bin`**：校验/探测失败仅 warning、不阻断注册（结果供 Spectre 命令执行接口使用），规则以 §4.2 为准 |
| **校验** | 探测获得并记录到 `expected`，只用于后续比对、**不参与业务**；运行期不一致 → **WARNING，不阻断**。唯一例外：**业务 role（gui/daemon/command/file）**的 host-key 指纹属于安全身份校验，不匹配 → **ERROR（阻断）**；spectre role 指纹缺失/不匹配仅 WARNING |

### 4.2 可提交参数

| 参数 | 类型 | 远程 | 本地 | 性质 |
|---|---|---|---|---|
| `mode` | 配置 | 必填 | 必填 | `local` / `remote`，申请方显式提供，不推断 |
| `user`（`^[A-Za-z0-9][A-Za-z0-9._-]{0,63}$`） | 配置 | 必填 | 必填 | 人类可读 id + 路径名，非安全凭证 |
| `ssh.default.host` / `ssh.default.user` | 配置 | remote 必填 | 不需要 | 五 role 缺省的登录主机/账号 |
| `ssh.default.jump_host` / `ssh.default.jump_user` / `ssh.default.proxy` | 配置 | 可选 | 不需要 | 五 role 缺省的跳板/代理 |
| `role.{gui,daemon,command,file,spectre}.host/user/jump_host/jump_user/proxy` | 配置 | 可选 | 不需要 | role 单端连接策略；缺省回退 `ssh.default.*`（§2.2） |
| `role.daemon.daemon_port` / `role.daemon.local_port` | 配置 | 可选 | 可选 | 缺省注册分配 |
| `token` | 配置 | 可选 | 可选 | 缺省自动生成 `^[A-Za-z0-9._-]{1,64}$` |
| `root.default` | 配置 | 可选 | 可选 | 各 role 文件根的全局默认基准（**实际默认 `~/.virtuoso-bridge/<userid>`**） |
| `role.{gui,daemon,command,file,spectre}.root` | 配置 | 可选 | 可选 | role 文件根；缺省 = `root.default/<role>`（`root.default` 默认 `~/.virtuoso-bridge/<userid>`） |
| `ssh.*` / `runtime.*` / `cdslog.*` | 配置 | 可选 | 可选 | 缺省见 §2 默认值 |
| `expected.ssh_endpoints`（显式指纹） | 校验 | 可选 | 不适用 | 用户显式提供 per-endpoint 指纹则校验后记录；key/算法见 §6.5 |
| `role.spectre.bin` | 环境 | 可选 | 可选 | 显式提供→校验；未提供→自动探测；**失败仅 warning、不阻断注册** |

### 4.3 探测、校验、期望如何进入注册表

1. **环境探测结果**：`environment.remote_python` 在 **daemon role** 探测并写入注册表（daemon 部署/启动消费）；`role.spectre.bin` 在 **spectre role** 探测/校验，结果记录供 Spectre 命令执行接口消费、失败仅 warning；daemon 端口空闲与各 role 文件根可写性只是校验结论，不写注册表；`root.default` 与 `role.*.root` 是配置，不探测、不可用时按配置校验拒绝。
2. **校验比对基准**：`expected.ssh_endpoints`（五个 role 解析后的 endpoint）、`expected.daemon_endpoint_hostname`、`expected.daemon_user` 由探测获得并记录，供第五步/运行期比对；不一致按 §4.1 的 WARNING（host-key 例外 ERROR）处理，不参与业务。
3. **系统配置**：`user`/`mode`/`ssh.*`/`runtime.*`/`cdslog.*` 等只在第二步做约束校验，不探测、不比对。

## 5. 输入安全与首信任（冻结）

- `user`：字符集见 §4.2；禁止 `/`、`\`、`..`、绝对路径；部署前 containment 校验，越界即注册失败。
- 跨平台路径规则：Windows 下 user 按**大小写不敏感**查重（`Alice` 与 `alice` 视为同一）；禁止保留设备名（`CON/PRN/AUX/NUL/COM1-9/LPT1-9`，含扩展名形式）与结尾 `.`/空格；路径规范化后冲突即拒绝注册。
- `token`：字符集见 §4.2；存 registry（0600）与 il/daemon；ControlPath 只用其不可逆 hash；轮换=删除用户重新注册。
- host-key 首信任优先级（不再依赖“首连即 TOFU”）：
  1. known_hosts 已存在且匹配 → 记录该指纹作为比对基准；
  2. 用户显式提供指纹 → 校验后记录；
  3. 两者皆无 → 注册失败，提示用户带外确认后添加，再重试。


## 6. Canonical 注册 API / Schema 附录（冻结）

### 6.1 注册请求 canonical 字段

| 字段 | 类型 | 必填 | 说明 |
|---|---|---|---|
| `mode` | `local` / `remote` | 是 | 显式提供，不推断 |
| `user` | string | 是 | §5 字符集与跨平台规则 |
| `ssh.default.host` / `ssh.default.user` | string | remote 必填 | 五 role 缺省的登录主机/账号 |
| `ssh.default.jump_host` / `ssh.default.jump_user` / `ssh.default.proxy` | string | 可选 | 五 role 缺省的跳板/代理 |
| `role.{gui,daemon,command,file,spectre}.{host,user,jump_host,jump_user,proxy}` | string | 可选 | role 单端连接策略；缺省回退 `ssh.default.*` |
| `root.default` | string | 可选 | 各 role 文件根的全局默认基准 |
| `role.{gui,daemon,command,file,spectre}.root` | string | 可选 | role 文件根；缺省 = `root.default/<role>`（`root.default` 默认 `~/.virtuoso-bridge/<userid>`） |
| `role.daemon.daemon_port` / `role.daemon.local_port` | int | 可选 | 缺省自动分配 |
| `token` | string | 可选 | 缺省自动生成 |
| `role.spectre.bin` | string | 可选 | 显式提供 → 校验；缺省 → 探测；失败仅 warning、不阻断 |
| `ssh.*` / `runtime.*` / `cdslog.*` | — | 可选 | 缺省见 §2 |
| `expected.ssh_endpoints` | map | 可选 | 显式 per-endpoint 指纹；key 见 §6.5 |

硬规则（实现必须一致）：

- 未知字段：**拒绝注册**（模型 `extra="forbid"`），不静默忽略；
- 可选字段：**空字符串视为未提供**；`null` 与缺省等价，进入模型后统一为默认值；
- 序列化：registry 持久化格式为 UTF-8 JSON、权限 `0600`、tmp + 原子替换（写锁语义见多用户设计 §11）。

### 6.2 registry 条目 canonical schema（合法 JSON 示例）

以 `user` 为键、`token` 唯一；字段与 §2 一致。单主机 remote 示例（五个 role 全部缺省，最终解析到同一个 endpoint）：

```json
{
  "users": {
    "alice": {
      "token": "a3f9c2d4e5f60718293a4b5c6d7e8f90",
      "mode": "remote",
      "ssh": {
        "default": {"host": "server-a", "user": "ssh-user",
                    "jump_host": null, "jump_user": null, "proxy": null},
        "backend": "openssh", "control_master": "auto", "tool_override": {}
      },
      "root": {"default": "~/.virtuoso-bridge/alice"},
      "route": {
        "gui":     {"host": null, "user": null, "jump_host": null, "jump_user": null, "proxy": null,
                    "root": null},
        "daemon":  {"host": null, "user": null, "jump_host": null, "jump_user": null, "proxy": null,
                    "root": null, "daemon_port": 65081, "local_port": 65082},
        "command": {"host": null, "user": null, "jump_host": null, "jump_user": null, "proxy": null,
                    "root": null},
        "file":    {"host": null, "user": null, "jump_host": null, "jump_user": null, "proxy": null,
                    "root": null},
        "spectre": {"host": null, "user": null, "jump_host": null, "jump_user": null, "proxy": null,
                    "root": null, "bin": "/opt/eda/cadence/SPECTRE241/bin/spectre"}
      },
      "expected": {
        "ssh_endpoints": {
          "v1:8c6325e8a41f89a4c29d81eb66db201c4414d33f87702607d23d43a1baf94b0b":
            "SHA256:RG8fY7m9O2Kp1Qx4sZ5n0Lw3eB6tVh8uJd9cIa7fGk0"
        },
        "daemon_endpoint_hostname": "server-a",
        "daemon_user": "ssh-user"
      },
      "environment": {"remote_python": "/opt/eda/cadence/tools.lnx86/python/64bit/bin/python3"},
      "runtime": {"thread_pool_size": 32, "channel_budget": 10, "connect_timeout": 15.0},
      "cdslog": {"log_level": "all", "log_max_bytes": 65536},
      "registered_at": 1726051200
    }
  }
}
```

- `role.*` 连接字段全为 `null` → 全部回退 `ssh.default.*`，五个 role 解析成同一 endpoint `["server-a","ssh-user","","",""]`，因此 `ssh_endpoints` 只有一项（key 算法见 §6.5）。
- `root.default` 已含用户目录（示例 `~/.virtuoso-bridge/alice`）、`role.*.root` 全为 `null` → 五个 role 的文件根分别为 `~/.virtuoso-bridge/alice/gui`、`.../daemon`、`.../command`、`.../file`、`.../spectre`。
- `role.spectre.bin` 是 spectre role 的专有字段；供 Spectre 命令执行接口使用（上层未来封装仿真流程）。
- `registered_at` 为注册流程生成的时间戳元数据，不属 §2 配置项，也不在 §6.1 可提交参数目录内。

### 6.3 mode × route 兼容矩阵

| mode | 五 role 的 host/user/jump/proxy | 各 role 文件根 | host-key 必检 |
|---|---|---|---|
| local | 五个 role 全部固定 `127.0.0.1` / 本机用户；无 SSH、无 jump/proxy | `root.default/<role>`，`root.default` 默认 `<本地工作目录>/<userid>` | 无 SSH，不检查 |
| remote | 连接字段缺省回退 `ssh.default.*`；一个账号最多五个不同目标 | `role.<name>.root`，缺省 `root.default/<role>`（`root.default` 默认 `~/.virtuoso-bridge/<userid>`）；相对路径按目标 role 的根解析 | gui/daemon/command/file 必检（ERROR）；spectre 仅 WARNING |

### 6.4 端口 reservation / TOCTOU

1. 第二步对 registry 内端口查重；
2. 第三步对目标机做 bind/占用探测；
3. 第四步部署前再次确认端口空闲，**冲突则自动重新分配并重试一次**，仍冲突即拒绝注册。

### 6.5 endpoint canonical key（版本化、无歧义）

```text
endpoint_key = "v1:" + SHA256(canonical_json)
canonical_json = json.dumps([host, user, jump_host, jump_user, proxy],
                            ensure_ascii=True, separators=(",", ":"))
```

规范化规则：

- `host` / `jump_host`：`strip` → 小写 → 去掉结尾 `.`（ASCII 主机名；IPv6 用标准压缩小写形式）；
- `user` / `jump_user`：`strip`，大小写敏感，不做其他变换；
- `proxy`：`strip` 后取原字符串；空 → `""`；
- 全部空段用 `""`；`null` 与 `""` 等价。

正例（`host=server-a, user=ssh-user, 其余空`）：

```text
canonical_json = ["server-a","ssh-user","","",""]
endpoint_key   = v1:8c6325e8a41f89a4c29d81eb66db201c4414d33f87702607d23d43a1baf94b0b
```

- 同 key = 同一 endpoint：共享一条 SSH 连接与 ControlMaster；不同 key 不共享；
- key 变更（主机重装、账号改名、跳板调整）视为**新 endpoint**：其指纹按 §5 首信任流程重新建立，不自动迁移。
