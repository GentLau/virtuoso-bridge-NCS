# virtuoso-bridge 使用说明（配套文档集）

这套文档面向**使用者**，回答"怎么用起来"和"每个参数是什么"，不涉及内部实现。
文档集可以整目录带走，作为软件的使用说明配套提供。

## 这套文档怎么分工

| 文档 | 给谁看 | 什么时候看 |
|---|---|---|
| [01 快速开始](01-快速开始.md) | 第一次上手的人 | 目标：**最快路径**把服务跑起来、注册完成、发出第一个成功请求 |
| [02 参考手册](02-参考手册.md) | 已经跑起来、要长期使用或做运维的人 | 接口形态、返回与错误、文件与路径、超时与并发、注册与用户管理、运维端点 |
| [03 业务包说明书](packages/README.md) | 要写具体操作的人 | 每个业务操作的**每个参数**、返回值、示例、常见错误 |
| [04 常见流程](04-常见流程.md)（附录） | 想直接照抄一条完整流程的人 | 建 cell、跑仿真、出版图/GDS、导入 Verilog、跑 Spectre/Calibre 的成串请求 |

推荐顺序：先照着《快速开始》走通一遍 → 需要哪个业务时翻《业务包说明书》对应包 →
遇到接口/错误/并发这类共性问题查《参考手册》。

## 版本说明

- 本文档集描述的是**当前代码实现**（随实现同步更新）；"代码未改完"的部分若与文档不一致，
  以实际返回为准，并请通过报障入口反馈（见《参考手册》"报障"一节）。
- 文档中的端口（8124 / 8127）是**默认示例值**，实际端口以启动参数为准。
- 命令示例里的 `TOKEN` 请替换为实际 token。
- `common.md` 与 `packages/<包>.md` 同时是 `/help/operations` 的**数据源**（每个操作一个小节，
  标题里 `—` 之后是清单里的 `summary`），所以这两个路径与标题格式不随意改动。
