> 日期：2026-09-17
> 来源：`doc/report/_explore/` 下五份旧代码提取报告（A 原理图/符号、B 版图/GDS、C Maestro/Spectre、D 库/Skill 工具/GUI、E 当前实现现状）

## 12. 开发顺序建议

- **P0**（纯 S/解析，离线可测）：library、skill_tooling、desktop_gui；顺带补公共测试基座 `FakeMiddle`（含 `query`）。
- **P1**（S 为主 + 少量文件）：schematic、symbol、layout。
- **P2**（多接口 + 外部工具轮询）：maestro、digital_import。
- **P3**（一次性命令 + 本地解析、平台适配）：spectre、visio_export。

依赖关系：所有包都依赖 P0 的公共模型与测试基座；schematic 依赖 symbol（自动生成）；digital_import 依赖 layout；maestro 的结果解析与 spectre 共享 PSF/CSV 解析器（spectre 包提供纯 Python 解析，maestro 复用）。
