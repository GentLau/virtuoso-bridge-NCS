## 6. 本轮发现并修复

1. **IL 日志开关判断错误**：`index(...) == 0` 使 `all/warn/error` 都不产生第二帧，真机表现为 Skill 超时；改为非 nil 判断后重新部署，真机日志增量恢复。
2. **Paramiko 常驻 shell 未生效**：`run_command` 过早走单次 exec，导致 cwd 不保留；调整为先走常驻 shell，再降级单次 exec，真机验证第二次 `pwd` 保留。
3. **reservation 残留**：按 spec v17 改为注册进程内存候选，不再创建 `registry.reservation`。
4. **max_sessions 作用域**：由 role 改为 endpoint，多个 role 同 endpoint 取最小值。
5. **registry schema**：改为顶层 `user -> entry`，移除 `users` wrapper，并清理锁 sidecar。
6. **进程风暴回归**：100 用户远端测试前后 ssh 进程数保持基线，未出现每请求新隧道。

## 7. 未覆盖/明确不支持

- split-host CDS.log 增量：spec 明确不支持；本版按普通路径读取，读不到时返回 warning。
- 跨机启动 daemon / 远程 launcher：spec 明确不支持。
- X11 显示链路本身、GUI 弹窗真实交互：本轮 GUI 只验证一次性命令通道，不验证 Visio/窗口管理业务。
- Spectre 高层仿真编排与结果解析：spec 明确留给上层后续；本轮验证 Spectre 命令通道与 bin 记录。
- OpenSSH backend 的真实远端五接口矩阵：本轮默认使用 paramiko 完成真机矩阵；OpenSSH 由单元/协议测试覆盖。
- jump/proxy 的真实高并发矩阵：endpoint canonical key、配置和单元测试覆盖，本轮真机 100 用户为直连路径。
- 100 个真实 Virtuoso CIW：规模压测使用协议级 fake daemon；真实 Virtuoso 使用 6 个既有实例 + 新注册 `vb11` 做功能验证。
