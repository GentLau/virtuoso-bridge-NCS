# 复核测试环境

> 版本：v2
> 日期：2026-09-11
> 定位：本文只描述**测试环境**；测试要跑什么见《复核测试计划.md》。SSH 连通性以《环境支持.md》为准。

## 1. 三台环境

| # | 名称 | 角色 | 系统 | 性能 | Virtuoso |
|---|---|---|---|---|---|
| 1 | 本机 | 客户端/开发机 | Windows | 强 | 无 |
| 2 | wsl-gent | Virtuoso 目标机 / 本地模式运行机 | Linux（WSL2 · AlmaLinux-8，运行于中转机 glis-desktop） | 强（15G） | 有（IC6.1.8，DISPLAY=:10） |
| 3 | 云服务器（SSH 别名 `vps`） | 远端端点（协议级 fake daemon）/ 可作命令·文件目标 | Linux（Debian，1.6G） | 弱 | 无 |

## 2. 网络拓扑

```text
本机 ──直连────────────────► vps（114.215.183.227）
本机 ──透明入口 ssh wsl-gent► wsl-gent（172.18.80.17，经 glis-desktop 中转）
```

- `ssh wsl-gent` 对使用方是**透明入口**：中转由基础设施完成，测试代码不感知、不配置跳板；底层路径见《环境支持.md》。
- `vps` 可被本机直连，也可被 wsl-gent 直连。

## 3. 每台机器预置

### 3.1 本机（Windows）

- 仓库工作副本 + `.venv`；
- 中层客户端：`BusinessServer`，每轮测试独立 registry 工作目录；
- SSH：`ssh vps` / `ssh wsl-gent`（BatchMode 无口令）；
- 协议级 fake daemon 可本地起多个（用于 100 用户本地段）。

### 3.2 wsl-gent

- 仓库副本 `/home/Gent/vb-ncs`（`src/`、`test/` 经 `scp` 同步），venv `.venv`；
- Virtuoso 多实例布局：`/home/Gent/project/<user>/.cdsinit` load `/home/Gent/.virtuoso-bridge/<user>/setup/virtuoso_setup.il`；
- 工具：`scripts/multi_virtuoso_pilot.py`、`scripts/restart_vb_virtuosos.py`；
- 内存预算：15G，单实例约 0.6G，本地/远端实例总量按计划控制，可用内存 <2G 停加。

### 3.3 vps（云，无 Virtuoso）

- 只跑协议级 fake daemon（STX/NAK + JSON，token 校验，backlog 128，端口 `6701+`），模拟“Skill 执行”；
- 命令/文件走标准 sshd/scp；
- 弱机限制：单轮并发、超时、SSH 会话数按弱机档位，在测试中实测上限。

## 4. 端口与命名约定

| 用途 | 用户命名 | 端口 |
|---|---|---|
| wsl 真实远端 | `vbNN` | `65101+` |
| wsl 本地模式 | `lcNN` | `65401+` |
| vps fake | `cloudNN` | `6701+` |
| 本机 fake / 隧道 | `uNN` | `65081+` |

- token 与端口一一对应，登记进各轮独立 registry；
- 每轮结束释放端口、关闭 fake daemon 与隧道、删除本轮 registry 工作目录。

## 5. 环境健康检查

```bash
ssh -o BatchMode=yes -o ConnectTimeout=15 vps echo ok
ssh -o BatchMode=yes -o ConnectTimeout=20 wsl-gent echo ok
```

通过标准：两行 `ok`；随后更新《环境支持.md》的“最后检查”行。

## 6. 复位

- wsl-gent：杀掉本轮 `project/<user>/CDS.log` 对应 Virtuoso 与 daemon；
- vps：杀掉本轮 fake daemon 进程；
- 本机：杀掉 `ssh.exe -L 65*` 残留隧道，删除本轮 registry 工作目录。
