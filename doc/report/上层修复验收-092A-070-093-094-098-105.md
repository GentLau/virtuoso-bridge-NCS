## P-070 细节

`test/live/packages/maestro_mc_e2e_tests.py` 当前最终真机运行 8/8：

- `mcmethod`、`mcnumpoints`、`mcnumbins`、`samplingmode`、`montecarloseed`、
  `mcstartingrunnumber`、`dutsummary`、`ignoreflag`、`mcreferencepoint`、
  `donominal`、`saveprocess`、`savemismatch`、`saveallplots`、`mcStopEarly`、
  `mcStopMethod`、`mcYieldTarget`、`mcYieldAlphaLimit` 全部批量写入并读回；
- `mcreferencepoint` 在无 reference point 时 ADE 不落 option，读回 `null`，写调用成功；
- `dutsummary` ADE 内部会追加尾终止符 `%#`，`read_config` 已剥离后返回；
- 17 项各送非法值，全部被点名拒绝；完整“不污染旧值”矩阵在离线
  `test/offline/unit/test_maestro_mc.py`；
- 正例 `tt + tt_mim + stat_res + mc_res` 跑 8 点 process MC，`MonteCarlo.0` done，
  Yield 表 `total_points=8`，输出含非空 `yield/mean/min/max`；
- 负例不挂 statistics，Spectre 报 `SPECTRE-16008`（process 无统计），TB 同时接受
  `SPECTRE-16008` / `SPECTRE-16012`。

产品侧同步改动：

- `maestro.run` 内部读取当前 mode 并显式拼 `maeRunSimulation(... ?runMode ...)`，
  避免 ADE 文档默认退回 Single Run；对外 `run` 仍不新增 `run_mode` 参数；
- `parse_yield_csv` 由 Yield Estimate 的 `passed/total` 推导 `error_points`；
  `read_results` 不再优先用 `maeGetOverallYield.ErrorPoints`（该字段在全通过样本上也会返回 1）；
- ADE `ASSEMBLER-1610` 未定义变量弹窗纳入已知对话框恢复；fixture 同时写入 global/test scope
  变量（`VDD/VB_BIAS/VCM_IN/VIN_DIFF/CLOAD/TEMP_C`）从源头避免弹窗。

## P-093 / P-094 / P-098 细节

- `_argv_for` 只在 `hier=true` 或 pex 阶段追加 `-turbo`；`hier=false` 的 DRC launcher
  已无 `-turbo`，真机 flat DRC completed。
- `job_state` 对“进程已死 + 有日志/产物 + 无完成标记”返回
  `failed/process_gone_without_report`；`calibre.py` 轮询快失败并在 blocking value 顶层
  回带 `failure_kind`。
- `calibre_timeout_probe.py` 用忽略 TERM 的假工具稳定制造“package deadline 已到、
  后台仍 running”的场景；真机返回 `status=timeout`，`status` 查询仍为 `running`。
