# 业务进程管理实现说明（顶层补充 v27）

> 日期：2026-09-20
> 依据：`spec/design-concepts/顶层/add-控制面与业务面.md` Draft v27 §1/§1.1/§3
> 范围：同机双进程父子模型、`/api/process/*` 管理端点、reload 热生效与 restart 排空

## 1. 交付内容

| 能力 | 实现位置 |
|---|---|
| 父子 supervisor（标准形态） | `src/server/supervisor.py`（`BusinessProcess` + `main`） |
| 同进程简化部署（`--single-process`） | `src/server/supervisor.py`（`SameProcessManager`） |
| 控制面端点 `GET /api/process/status`、`POST /api/process/reload|restart`、审计 | `src/register/server.py` |
| 业务子进程：可变准入上限、排空、内部通道事件 | `src/server/api_server.py`（`ApiServer.set_max_inflight/wait_idle`、`_supervised_loop`） |
| reload 不打断在途：延迟关闭 token 缓存 | `src/transport/middle.py`（`_in_flight`/`_retire_pending`、`reload_registry`） |

## 2. 行为对照

- **父子模型**：管理进程 `python -m server.supervisor` 负责拉起业务子进程（`server.api_server --supervised`），子进程不 detach；管理进程退出 → 子进程 stdin EOF → 子进程排空后自行退出（v27 §1）。
- **状态**：`starting`（已拉起、端口未 ready）/ `ready` / `crashed`（意外退出，不自动拉起）；`status` 返回 pid/port/work_dir/startup_args（token 脱敏）/`same_process`/`last_error`。
- **reload**：经 spawn 时的 stdin 内部通道触发；业务进程重新导入 `registry.json`（快照立即切换，新 token 立即生效/被删 token 立即失效）与 `config.json`（`business_thread_pool_size` 热生效）；旧 token 连接缓存等其 in-flight 归零后再关闭，因此**不打断在途请求**。
- **restart**：先置 `draining`（业务监听保持，新请求 `503 + Retry-After: 1`），等在途排空至 **30s** 上限，超时强杀；随后按原启动参数重新拉起，**新子进程 ready 后**才返回 2xx；失败 → 5xx + `status=crashed`。
- **未托管 / 同进程**：未托管（`process_manager=None`）→ `409`；同进程 `restart` → `501`，`reload` 原地重导。
- **审计**：管理动作写 `log/audit.log`（ts/action/target/ok/detail），不含凭据。

## 3. 启动方式

```bash
# 标准形态（父：控制面 8124，子：业务面 8127）
PYTHONPATH=src python -m server.supervisor \
  --control-host 127.0.0.1 --control-port 8124 \
  --business-host 127.0.0.1 --business-port 8127 \
  --work-dir <工作目录>

# 简化形态（两 face 同进程；restart 返回 501）
PYTHONPATH=src python -m server.supervisor ... --single-process
```

管理调用（管理员 token `Authorization: Bearer <token>`）：

```bash
curl -H "Authorization: Bearer $ADMIN" http://127.0.0.1:8124/api/process/status
curl -X POST -H "Authorization: Bearer $ADMIN" -H "Content-Type: application/json" \
  -d '{"target":"business"}' http://127.0.0.1:8124/api/process/reload
curl -X POST -H "Authorization: Bearer $ADMIN" -H "Content-Type: application/json" \
  -d '{"target":"business"}' http://127.0.0.1:8124/api/process/restart
```
