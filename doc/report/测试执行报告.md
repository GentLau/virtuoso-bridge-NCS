## 8. 期间发现并修复的实现缺陷（证据）

1. **IL 双帧乱序**：并发下 1/120 的 `RBDToken` 返回值被 log-meta 帧替换。修复：IL 把 value 帧与 meta 帧拼接为**一次 `ipcWriteProcess`**。复测 120 并发 → `bad 0`。
2. **local 常驻会话 stderr 文件读法**：`type` 读临时文件偶发“Could Not Find”。修复：shell 只重定向 stderr 到文件，由 Python 在命令结束后读回。复测 100 用户 600 命令 → `bad_value 0`。
