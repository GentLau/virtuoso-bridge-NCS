## 2. P-043：真实缺陷，已修（1 行）

### 2.1 判定依据（不是照抄报告）

* 该文件由 `src/common/deploy.py:42` 在 **远端 python major == 2** 时部署
  （`src/common/remote_paths.py:60` 选择 `ramic_bridge_daemon_27.py`），
  spec《中层配置文档》中 `role.daemon.python` 是环境事实（显式→校验、缺省→探测），
  没有"只支持 python3"的口径——即 py2.7 daemon 是**在册功能**；
* 文件含非 ASCII 注释（285 行起）但无 PEP 263 coding cookie：
  **标准（stock）Python 2.7 在启动阶段即 SyntaxError**，daemon 完全起不来；
* 加 cookie 是注释级改动，不触碰协议/接口/参数，无 spec 冲突。

### 2.2 复现（红）与验证（绿）

用 AlmaLinux python2 RPM 解出的**stock Python 2.7.18**（避免 Cadence 自带解释器
的宽容差异；Cadence 的 py2.7 即使无 cookie 也能编译，不能作为判据）：

```text
$ python2.7 orig_daemon.py
  File "orig_daemon.py", line 285
SyntaxError: Non-ASCII character '\xe7' in file orig_daemon.py on line 286,
but no encoding declared; see http://python.org/dev/peps/pep-0263/ ...
```

修复后同一解释器跑测试工程师的探针（`test/semi/probes/py27_daemon_probe.py`）：

```json
{"version": "Python 2.7.18", "passed": 5, "total": 5}
```

覆盖：`listen` / `reject-bad-token` / `reject-bad-log-level` /
`reject-bad-log-max-bytes` / `timeout-watchdog-answers`。

## 4. P-048：驳回（与 spec 冲突），给出规范路径

报告症状（standalone `python -m server.api_server` 起业务面、注册表变更后
旧进程一直 `invalid token`）属实，但**修法与 spec 冲突**：

| 报告建议 | spec 口径 | 结论 |
|---|---|---|
| ① 业务面提供 HTTP reload | 《控制面与业务面》§4：业务端口只有 `POST /api/operation`、`GET /health`、`GET /help`；"业务端口只做 operation 调度，**不开注册/管理/配置端点**" | **驳回** |
| ② 按 registry mtime 自动重载 | 同文档 §5：config/registry "运行期不读文件、**请求期零文件 IO**"；注册表一次性导入内存 | **驳回** |

规范路径（已有实现与 TB，均绿）：

1. 用 `python -m server.supervisor` 起标准双进程（控制 8124 + 业务 8127）；
2. 注册表变更后调控制面 `POST /api/process/reload`（管理权限）→ 经 spawn 建立的
   内部控制通道让业务子进程重导 registry/config，并退役旧 token 缓存；
3. 若坚持 standalone 业务进程（非规范拓扑），变更后必须**重启该进程**。

证据（本轮复跑）：

```text
test/offline/integration/test_business_child_supervision.py
  ::TestSupervisedBusinessChild::test_reload_swaps_registry_snapshot  PASS
  （未知 token 先失败 → 写 registry.json → reload → 同 token 立即可用）
  ::TestSupervisedBusinessChild::test_reload_round_trip                PASS
```

建议测试侧把"standalone 8127"从长期常驻改成 supervisor 管理，或在测试环境文档
写明"改注册表后需重启 8127"。
