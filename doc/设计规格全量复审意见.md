## 三、本轮确认通过的重点

- remote role 的 SSH 凭据解析规则明确：`key_dir` 缺省为客户端 `~/.ssh`，`key` 必填且只能是文件名；
- `local` role 不允许提交 SSH 目标或凭据字段；
- 凭据复用按公钥指纹查重；`enhanced_token` 可承载管理员 token 或任一已登记持有者 token；
- `/api/register` 的 apply 权限、session token、enhanced_token 和校验失败语义一致；
- 同一 token、同一 endpoint 只有在解析后凭据一致时才复用业务连接；
- endpoint canonical key 不含 SSH 凭据，避免身份和凭据混淆；
- `mode=local` 单用户形态、管理权限和多用户 remote 隔离的规则跨路由、注册、控制面一致；
- per-role 用户组、query、display、common.config、注册失败重试和进程管理既有口径没有回退。
